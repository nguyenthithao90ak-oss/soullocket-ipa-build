แปลเอกสารฉบับ 2026-09-28 ติดต่อฝ่ายสนับสนุนหากถ้อยคำไม่ชัดเจนหรือแตกต่างกันระหว่างภาษา

1. เทคโนโลยีที่ใช้ 2. ประเภทของข้อมูลที่จัดเก็บ 3. คำว่า "จำเป็น" และ "ทั้งหมด" หมายถึงอะไรในปัจจุบัน 4. ผู้ให้บริการที่เกี่ยวข้อง 5. การจัดการและการถอนตัวเลือก 6. การเก็บรักษาและผลกระทบของการล้างข้อมูล 7. อัพเดทและติดต่อ

1. เทคโนโลยีที่ใช้

เว็บอาจใช้คุกกี้, localStorage, sessionStorage และ IndexedDB แอปนี้ใช้ SharedPreferences ที่เก็บข้อมูลการรับรองความถูกต้องที่ปลอดภัย ฐานข้อมูลในเครื่อง และแคชรูปภาพ/ไฟล์ คุกกี้เหล่านี้ไม่ใช่คุกกี้ประเภทเดียวกันทั้งหมด แต่คุกกี้ทั้งหมดอาจจัดเก็บข้อมูลไว้ในอุปกรณ์ของคุณ

หน้านโยบายเหล่านี้ไม่ได้ฝังโฆษณาหรือโค้ด Analytics แบบฟอร์มการลบบัญชีจะส่งข้อมูลเมื่อคุณส่งเท่านั้น แอปหลักและหน้าเนื้อหาอื่นๆ มีพฤติกรรมการประมวลผลแยกกัน

2. ประเภทของข้อมูลที่จัดเก็บ

หมวดหมู่วัตถุประสงค์และตัวอย่าง
การรับรองความถูกต้องและความปลอดภัยเซสชันการลงชื่อเข้าใช้ โทเค็น สถานะอุปกรณ์ และตัวเลือกทางกฎหมาย ช่วยรักษาและปกป้องการเข้าถึง
การตั้งค่าของคุณภาษา ลักษณะ แท็บ การกำหนดค่าการล็อคหรือการแสดงผล ตัวเลือกเหล่านี้อาจถูกบันทึกไว้แม้ว่าคุณจะเลือก "จำเป็น" ก็ตาม
ข้อมูลและแคชแบบร่าง คิวการซิงโครไนซ์ รูปภาพ/ไฟล์ที่ดาวน์โหลด และฐานข้อมูลท้องถิ่นอาจมีเนื้อหาส่วนตัว พวกเขาจะไม่เปิดเผยตัวตนโดยอัตโนมัติ
การวินิจฉัย/การวัดผลFirebase Analytics และ Crashlytics อาจประมวลผลเหตุการณ์ ข้อมูลอุปกรณ์ ข้อผิดพลาด และตัวระบุทางเทคนิคตามการผสานรวม
การโฆษณาและการทำธุรกรรมสถานะความยินยอมในการโฆษณา ตัวระบุการโฆษณา การโต้ตอบ การซื้อหรือโทเค็นการตรวจสอบรางวัล กิจกรรมการโฆษณาบางอย่างไม่ควรถูกจัดประเภทเป็นที่เก็บข้อมูลที่จำเป็น

3. “จำเป็น” และ “ทั้งหมด” หมายถึงอะไร

ในการผสานรวมใหม่ "Essential" จะปิดใช้การรวบรวม Analytics/Crashlytics และบล็อกการเริ่มต้นและการโหลดโฆษณาผ่านแอป “ทั้งหมด” อนุญาต SDK เสริมเหล่านี้ โฆษณาจะต้องได้รับอนุญาตจาก Google UMP และเป็นไปตามการอนุญาตของระบบปฏิบัติการ แอพจะบันทึกตัวเลือก เวลา และเวอร์ชันของเอกสารบนอุปกรณ์ ตัวเลือกเดิมที่ไม่มีเวอร์ชันต้องได้รับการยืนยันอีกครั้ง

การถอนจะบล็อกคำขอใหม่และลบโฆษณาที่โหลดในแอป ไม่สามารถเรียกคืนข้อมูลที่ส่งไปแล้วหรือกำลังเชื่อมต่ออยู่ได้ Native SDK อาจเก็บรายงานข้อขัดข้องไว้ในเครื่อง แอปขอให้ลบรายงานที่ยังไม่ได้ส่งก่อนที่จะเปิดใช้งานการรวบรวม แอปเวอร์ชันเก่าอาจไม่มีการควบคุมเหล่านี้

“Essential” ไม่ได้ปิดการลงชื่อเข้าใช้ การซิงโครไนซ์ ธุรกรรม ความปลอดภัยของระบบ หรือการเชื่อมต่อของบุคคลที่สามทุกครั้ง ไม่ได้แทนที่สิทธิ์ข้อมูลที่ละเอียดอ่อน สิทธิ์ของระบบปฏิบัติการ หรือการยินยอมโฆษณาแยกต่างหาก

4. ผู้ให้บริการที่เกี่ยวข้อง

Firebase/Google Sign-In, Facebook เมื่อใช้ในการลงชื่อเข้าใช้, โฆษณาบนมือถือของ Google/AdMob, แพลตฟอร์มการชำระเงิน, บริการแผนที่ และโครงสร้างพื้นฐาน Cloudflare อาจใช้โทเค็น แคช หรือสถานะทางเทคนิคสำหรับคุณสมบัติต่างๆ เนื้อหา แบบอักษร และไฟล์ภายนอกที่ฝังไว้อาจเชื่อมต่อกับผู้ให้บริการเมื่อโหลด

หมวดหมู่ข้อมูล วัตถุประสงค์ และขอบเขตการแบ่งปันมีอธิบายไว้ใน นโยบายความเป็นส่วนตัว. นโยบายของผู้ให้บริการไม่ได้แทนที่ความรับผิดชอบของ SoulLocket สำหรับการบูรณาการ

5. การจัดการและการถอนตัวเลือก

  • เปิดการตั้งค่า → ตัวเลือกความเป็นส่วนตัวเพื่อสลับระหว่าง "จำเป็น" และ "ทั้งหมด" เลือก "จำเป็น" เพื่อเพิกถอนการอนุญาตสำหรับกลุ่ม SDK เสริมโดยไม่ต้องล้างข้อมูลแอป ตัวเลือกความเป็นส่วนตัวของโฆษณาจะเปิดตัวเลือก UMP ของ Google หากมี
  • จัดการตำแหน่ง กล้อง ไมโครโฟน การแจ้งเตือน สุขภาพ และการโฆษณา/การติดตามสิทธิ์ในการตั้งค่าระบบปฏิบัติการของคุณ การควบคุมที่ใช้ได้จะแตกต่างกันไปตามอุปกรณ์
  • ใช้การตั้งค่าความเป็นส่วนตัวของเบราว์เซอร์ของคุณเพื่อตรวจสอบ/ลบข้อมูลเว็บไซต์ การบล็อกข้อมูลสำคัญอาจทำให้เซสชันการลงชื่อเข้าใช้ของคุณสิ้นสุดลงหรือขัดขวางฟีเจอร์ต่างๆ
  • ติดต่อฝ่ายสนับสนุนเกี่ยวกับสิทธิ์ความเป็นส่วนตัวเมื่ออินเทอร์เฟซขาดการดำเนินการที่จำเป็น การล้างข้อมูลแอปจะต้องไม่ถือว่าเป็นวิธีเดียวที่จะเพิกถอนความยินยอม

6. การเก็บรักษาและผลกระทบของการล้างข้อมูล

ข้อมูลเซสชันอาจหมดอายุเมื่อสิ้นสุดเซสชัน การตั้งค่าและฐานข้อมูลท้องถิ่นอาจยังคงอยู่จนกว่าคุณจะล้างข้อมูลแอป/เว็บไซต์ แคชจะมีอายุการใช้งานของตัวเองและสามารถดาวน์โหลดได้อีกครั้ง การออกจากระบบไม่รับประกันว่าแคช การดาวน์โหลด หรือการสำรองข้อมูลอุปกรณ์ทั้งหมดจะถูกลบออก

ส่งออกหรือซิงโครไนซ์ข้อมูลที่ยังไม่ได้บันทึกก่อนที่จะล้างพื้นที่เก็บข้อมูล การถอนการติดตั้งแอป การลบคุกกี้ หรือการปิดการอนุญาตจะไม่ลบบัญชี ข้อมูลเซิร์ฟเวอร์ หรือการสมัครสมาชิกของคุณ ดู คู่มือการลบบัญชีและข้อมูล.
