SoulLocket-Benutzerhandbuch

1. Erste Schritte

  1. Registrieren/melden Sie sich mit der von Ihnen gewählten Methode an. Lesen Sie die Bedingungen, Richtlinien und Datenschutzoptionen.
  2. Komplette Profil-/Hauseinrichtung, falls gewünscht. Überprüfen Sie Ihren Namen, Ihren Avatar und Ihre Konto-E-Mail-Adresse in den Einstellungen.
  3. Gewähren Sie Kamera-, Mikrofon-, Standort- oder Benachrichtigungsberechtigungen nur, wenn Sie die entsprechende Funktion benötigen. Sie können Berechtigungen in Ihrem Betriebssystem ändern.
  4. Lesen Erste Einrichtung und speichern Sie einen kurzen Eintrag, um die Synchronisierung zu überprüfen.

2. Kopplung und verschiedene QR-Codes

Zwei Konten koppeln

  1. Offen Einstellungen → Mit Ihrem Partner verbinden.
  2. Die Person, die ihr Haus behalten möchte, wählt Erstellen Sie Ihren Code, wählt einen Ablaufzeitraum und sendet die 12-stellige Einladung oder den QR an seinen Partner.
  3. Die andere Person wählt Geben Sie den Code Ihres Partners ein, dann gibt/fügt den Code ein oder scannt den Einladungs-QR.
  4. Lesen Sie die Datenwarnung, senden Sie die Anfrage und warten Sie auf die Genehmigung des Erstellers. Die Kenntnis einer Haus-ID gewährt nicht automatisch Zutritt.
  5. Überprüfen Sie abschließend beide Avatare, Namen und das Verbindungsdatum. Über die Verknüpfung „Mit deinem Partner verbinden“ werden auch beide Avatare und der Verbindungsstatus angezeigt.
Die beiden Datenräume werden nicht automatisch zusammengeführt: Die Person, die den Code eingibt, bewegt sich zum Haus des Erstellers. Ein altes Haus ohne verbleibende Mitglieder kann aufgeräumt werden. Exportieren oder speichern Sie alles, was Sie benötigen, bevor Sie es bestätigen. Veröffentlichen Sie keine Einladungscodes oder QR-Bilder.

Drei verschiedene Arten von Codes

  • Kopplungscode/QR: eine ablaufende, einmalige Einladung, die einer Genehmigung bedarf.
  • Login-QR: Das Gerät, das sich anmelden möchte, zeigt den Code an. Ein bereits angemeldetes Gerät scannt und bestätigt es, wenn dieser Flow verfügbar ist. Scannen Sie keine Anmeldecodes von Fremden.
  • Profil/Haus-QR: öffnet je nach Funktion ein Profil oder teilt es; er selbst gewährt keine Mitgliedschaft.

Wenn Sie in den Einstellungen „Koppeln“ auswählen, bedeutet dies nicht, dass Sie gekoppelt sind. Wenn Sie bereits einen Partner haben, aber immer noch die Codeerstellung sehen, überprüfen Sie das Konto/Haus und die Verbindung und wenden Sie sich dann an den Support. Erstellen Sie kein neues Haus zur Fehlerbehebung.

3. Reflexionen schreiben und Erinnerungen speichern

  1. Offen Tagebuch, dann wählen Reflexionen schreiben bzw Erinnerungen um Fotos hinzuzufügen.
  2. Wählen Sie Ihre Stimmung/Ihren Inhalt aus und speichern Sie. Warten Sie auf den Erfolg und prüfen Sie dann, ob der Eintrag/das Foto in der Liste erscheint.
  3. Wenn die Sitzung abgelaufen ist, bewahren Sie eine Kopie der nicht gesendeten Inhalte auf, bevor Sie sich wieder beim richtigen Konto anmelden.
  4. Wenn die Synchronisierung unvollständig ist, überprüfen Sie die Konnektivität, das richtige Haus und den Upload-Status. Löschen Sie keine App-Daten und deinstallieren Sie sie nicht, solange nicht synchronisierte Entwürfe verbleiben.

Exportieren/laden Sie Inhalte mithilfe der verfügbaren Funktionen herunter und überprüfen Sie die gespeicherten Dateien. Exportierte Dateien liegen außerhalb der Datenschutzkontrollen der App. Bewahren Sie sie sicher auf.

4. Chat und Dienstprogramme

Verwenden Sie die in Ihrer App-Version verfügbaren Abschnitte, um Nachrichten zu senden, Inhalte zu teilen, Karten anzuzeigen oder Dienstprogramme/Spiele zu öffnen. Nicht jede Funktion ist auf jeder Plattform verfügbar.

  • Überprüfen Sie Empfänger und Sichtbarkeit, bevor Sie Beiträge, Fotos, Karten oder Links senden.
  • Die Karten-/Standortfreigabe kann im Hintergrund ausgeführt werden, wenn sie aktiviert und erlaubt ist; Deaktivieren Sie es in der Funktion oder im Betriebssystem, wenn Sie es nicht mehr teilen möchten.
  • Für die Aufnahme ist das Mikrofon erforderlich. Zum Fotografieren oder Scannen von QR-Codes ist die Kamera erforderlich. Für reine Textnachrichten ist kein Kamera-/Mikrofonzugriff erforderlich, nur um Text zu senden.
  • Bei Belästigung melden/blockieren oder den Support kontaktieren. AI dient nur als Referenz; Senden Sie keine Kontogeheimnisse an AI.

5. Sicherheit und Synchronisierung

Aktivieren Sie die PIN-/biometrische Sperre, sofern unterstützt, überprüfen Sie angemeldete Geräte und überprüfen Sie die Datenschutzeinstellungen. Eine PIN sperrt den Zugriff auf die Schnittstelle; Die Berechtigungen Ihres Hauspartners werden dadurch nicht geändert.

Durch die Anmeldung beim richtigen Konto auf einem neuen Gerät können synchronisierte Daten wiederhergestellt werden. Entwürfe, Caches, nur lokale Inhalte oder ausstehende Uploads werden möglicherweise nicht übertragen. Bevor Sie das Gerät wechseln, überprüfen Sie Ihre Daten und exportieren Sie alles Wichtige.

Geben Sie keine Passwörter, PINs, Einmalcodes oder Login-QR-Codes weiter. Schwärzen Sie private Informationen in Fehler-Screenshots.

6. Transaktionen und Vorteile

Wenn Ihre App-Version kostenpflichtige Funktionen bietet, lesen Sie Preise, Dauer und Verlängerungsbedingungen auf dem Bestätigungsbildschirm. Nutzen Sie das Einkaufskonto, um Vorteile wiederherzustellen. Bei fehlenden Vorteilen/Prämien senden Sie die Transaktions-ID oder die Ereigniszeit zur Abstimmung an den Support. Kaufen Sie nicht erneut als Schritt zur Fehlerbehebung.

Durch die Deinstallation der App oder das Löschen Ihres Kontos wird ein Abonnement nicht automatisch gekündigt. Verwalten Sie Pläne über die entsprechende Zahlungsplattform. Siehe die Transaktionsbedingungen.

7. Fehlerbehebung

  • Anmeldung/abgelaufene Sitzung: Überprüfen Sie die Konnektivität, die Gerätezeit und die richtige Anmeldemethode für das Konto. Speichern Sie Entwürfe, bevor Sie sich abmelden.
  • Einladungsfehler: Überprüfen Sie alle 12 Ziffern, das Ablaufdatum, ob es verwendet wurde oder auf Genehmigung wartet, und den QR-Typ. Geben Sie den Code manuell ein, wenn der Scanvorgang fehlschlägt.
  • Reflexionen/Fotos werden nicht gespeichert: Bewahren Sie eine Kopie auf, überprüfen Sie die gespeicherte Liste, um Duplikate zu vermeiden, und melden Sie das Problem, falls sie immer noch fehlt.
  • Alte Daten fehlen: Überprüfen Sie Ihr Konto und Ihr Haus. Löschen Sie keine Daten oder koppeln Sie sie erneut, bevor Sie die Ursache ermittelt haben.

Senden Sie Ihre Plattform, Version, Bildschirm, Aktion und Fehlerzeit an Support. Senden Sie keine Passwörter/PINs/Einmalcodes. Informationen zum Löschen von Daten finden Sie im Anleitung zur Kontolöschung anstatt nur die App zu deinstallieren.
