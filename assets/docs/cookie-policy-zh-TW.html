1. 使用的技術

網路可能使用 cookie、localStorage、sessionStorage 和 IndexedDB。該應用程式使用 SharedPreferences、安全身份驗證儲存、本機資料庫和映像/檔案快取。這些 cookie 並不都是同一類型，但它們都可能在您的裝置上儲存資料。

這些政策頁面不嵌入廣告或分析程式碼。帳戶刪除表單僅在您提交時才會傳送資料；主應用程式和其他內容頁面具有單獨的處理行為。

3.「必需」和「全部」是什麼意思

在新的整合中，「Essential」會停用 Analytics/Crashlytics 收集並阻止廣告初始化和透過應用程式載入。 「全部」允許這些可選 SDK；廣告仍必須獲得 Google UMP 的允許並遵循作業系統權限。應用程式記錄裝置上的選擇、時間和文件版本；沒有版本的遺留選擇需要再次確認。

提款會阻止新請求並刪除應用程式中載入的廣告；它無法呼叫已傳送的資料或已進行的連線。原生 SDK 可能會在本機儲存崩潰報告；該應用程式請求在啟用收集之前刪除未發送的報告。較舊的應用程式版本可能不包含這些控制項。

「基本」不會關閉登入、同步、交易、系統安全或每個第三方連線。它不會取代敏感資料權限、作業系統權限或單獨的廣告同意。

4. 相關供應商

Firebase/Google 登入、用於登入的 Facebook、Google 行動廣告/AdMob、支付平台、地圖服務和 Cloudflare 基礎架構可能會使用令牌、快取或技術狀態來實現其功能。嵌入的內容、字體和外部文件在載入時可以連接到提供者。

資料類別、用途和共享範圍描述於 隱私權政策。提供者的政策不能取代 SoulLocket 的整合責任。

5. 管理和撤銷選擇

  • 開啟設定 → 隱私選項，在「基本」和「全部」之間切換。選擇「基本」可撤回對選用 SDK 群組的權限，而不清除應用程式資料。廣告隱私權選擇會開啟 Google UMP 選擇（如果適用）。
  • 在作業系統設定中管理位置、攝影機、麥克風、通知、健康狀況和廣告/追蹤權限。可用的控制項因設備而異。
  • 使用瀏覽器的隱私設定來檢查/刪除網站資料。阻止重要資料可能會結束您的登入工作階段或中斷功能。
  • 當介面缺乏所需的操作時，請聯絡支援人員以了解隱私權。清除應用程式資料不得被視為撤回同意的唯一方法。

6. 清除資料的保留和影響

會話資料可能會在會話結束時過期；首選項和本機資料庫可能會保留，直到您清除應用程式/網站資料。快取有自己的生命週期，可以再次下載。註銷並不保證刪除所有快取、下載或裝置備份。

在清除儲存之前匯出或同步未儲存的資料。 卸載應用程式、刪除 cookie 或停用權限不會刪除您的帳戶、伺服器資料或訂閱。請參閱 帳戶和資料刪除指南.
