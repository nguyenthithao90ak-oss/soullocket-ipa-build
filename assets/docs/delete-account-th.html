แปลเอกสารฉบับ 2026-09-28 ติดต่อฝ่ายสนับสนุนหากถ้อยคำไม่ชัดเจนหรือแตกต่างกันระหว่างภาษา

1. เลือกขอบเขตที่ถูกต้อง 2. ระยะเวลารอในกระแสปัจจุบัน 3. จัดการข้อมูลและข้อจำกัดในปัจจุบัน 4. การดำเนินการในแอป 5. ขอลบนอกแอป

1. เลือกขอบเขตที่ถูกต้อง

  • การลบบัญชี: ขอให้ปิดบัญชีการลงชื่อเข้าใช้ปัจจุบันของคุณและการจัดการข้อมูลที่เกี่ยวข้อง จะไม่ลบบ้านทั้งหมดของคู่ของคุณโดยอัตโนมัติ
  • การแยกย่อย / การลบข้อมูลเฮาส์: ขอล้างพื้นที่ที่ใช้ร่วมกันและอาจส่งผลต่อข้อมูลของทั้งสองคน มันไม่ได้ลบบัญชีการลงชื่อเข้าใช้ด้วยตนเอง
  • การลบเนื้อหาส่วนบุคคล: ใช้การดำเนินการลบไดอารี่ รูปภาพ โพสต์ หรือยูทิลิตี้ที่เกี่ยวข้อง หากคุณต้องการลบเนื้อหาบางส่วนเท่านั้น
ส่งออก/บันทึกสิ่งที่คุณต้องการก่อนยืนยัน การถอนการติดตั้งหรือการออกจากระบบไม่ได้แทนที่คำขอลบ การลบบัญชีจะไม่ยกเลิกการสมัครสมาชิกกับร้านค้าชำระเงินโดยอัตโนมัติ

2. ระยะเวลารอในกระแสปัจจุบัน

เซิร์ฟเวอร์ส่งคืนเวลาที่แน่นอนและแสดงในแอป ระยะเวลาด้านล่างอธิบายถึงรหัสประมวลผลปัจจุบัน ไม่ใช่การรับประกันว่าทุกสำเนาจะถูกลบในเวลาอันแม่นยำ

คำขอการจัดตารางเวลา
การลบบัญชีโดยไม่มีบ้านที่ระบุที่ถูกต้องกำหนดไว้ 3 วันหลังจากการร้องขอ
การลบบัญชีกับบ้านกระแสปัจจุบันกำหนดให้รอ 30 วัน แม้ว่าสภายังไม่มีสมาชิกสองคนก็ตาม หากสมาชิกที่มีสิทธิ์รายอื่นยืนยัน เวลาจะถูกรีเซ็ตเป็น 3 วันหลังจากการยืนยันนั้น
การลบบ้านในโหมดเดียวกำหนดการหลังจาก 3 วัน
การเลิกรา/คู่รัก การลบบ้านรอการยืนยันจากสมาชิกท่านอื่นหรือกำหนดเวลารอ 30 วัน หลังจากย้ายไปยังสถานะตามกำหนดการแล้ว จะมีเวลาเพิ่มอีกวันก่อนการลบ
คำขอนอกแอปสร้างคำขอการสนับสนุนสำหรับการตรวจสอบและการจัดการ ไม่ใช่การลบทันที ไม่มีคำสัญญาว่าจะเสร็จสิ้นโดยอัตโนมัติภายใน 7 วัน ฝ่ายสนับสนุนจำเป็นต้องแจ้งความคืบหน้า/เวลาที่เหมาะสมหลังการยืนยัน

สำหรับบ้านที่ใช้ร่วมกัน ผู้ขอไม่สามารถยืนยันตนเองโดยการสลับไปยังอุปกรณ์อื่นที่ลงชื่อเข้าใช้ด้วยบัญชีเดียวกัน ก่อนกำหนดเวลาและก่อนเริ่มการประมวลผล คุณสามารถยกเลิก/ถอนคำขอได้หากอินเทอร์เฟซยังอนุญาตอยู่ ไม่มีการรับประกันการกู้คืนหลังจากการลบอย่างถาวร

3. จัดการข้อมูลและข้อจำกัดในปัจจุบัน

ขั้นตอนการลบบัญชีปัจจุบันจะล้างโปรไฟล์บัญชี ลิงก์สมาชิก โทเค็นสถานะ/อุปกรณ์ และคำขอ/รายงานการสนับสนุนที่เชื่อมโยงกับ UID จากนั้นจะลบบัญชีการตรวจสอบสิทธิ์ ขั้นตอนการลบบ้านจะล้างบ้าน โปรไฟล์สาธารณะ สาขาข้อความ การแจ้งเตือน เพื่อน GPS คำเชิญ และข้อมูลที่เชื่อมโยงกับบ้านภายในขอบเขตที่นำไปใช้

อย่าถือว่าการลบบัญชีเป็นการลบเนื้อหาเก่าทุกชิ้นพร้อมกัน เนื้อหา Shared House, สื่อ Cloudflare R2, ข้อมูล Firestore บางส่วน หรือบันทึกอื่นๆ อาจต้องมีการตรวจสอบและการจัดการเพิ่มเติม กลไกปัจจุบันไม่เพียงพอที่จะรับประกันการล้างข้อมูลร้านค้าเหล่านี้ทั้งหมดอย่างสมบูรณ์ ระบุข้อมูลส่วนบุคคลที่เหลืออยู่ที่คุณต้องการลบในคำขอการสนับสนุนของคุณ

สำเนาที่ดาวน์โหลดที่ผู้อื่นเก็บไว้ ภาพหน้าจอ และการส่งออกอุปกรณ์ไม่สามารถเรียกคืนจากระยะไกลได้ ข้อมูลที่เก็บไว้ตามภาระผูกพันทางกฎหมาย การจัดการการฉ้อโกง หรือข้อพิพาทจะต้องถูกจำกัด คุณอาจถามว่ามีอะไรเก็บไว้ ทำไม และนานแค่ไหน ไม่มีคำมั่นสัญญาว่าเนื้อหาในชุมชนทั้งหมดจะไม่เปิดเผยตัวตนโดยอัตโนมัติ

4. การดำเนินการในแอป

  1. ลงชื่อเข้าใช้บัญชีที่ถูกต้อง เปิด การตั้งค่า และค้นหา การลบบัญชีและข้อมูล หรือ การแยก/ลบข้อมูล.
  2. อ่านขอบเขตที่ได้รับผลกระทบและขั้นตอนการยืนยัน การลบบัญชีรวมถึงอีเมล/การยืนยันรหัสแบบครั้งเดียว ป้อนรหัสในแอปอย่างเป็นทางการเท่านั้น ไม่ใช่ในข้อความสนับสนุน
  3. ตรวจสอบข้อความแสดงความสำเร็จและเวลาที่กำหนด แอปอาจออกจากระบบหลังจากสร้างคำขอลบบัญชี
  4. หากต้องการถอนตัวก่อนถึงกำหนดเวลา ให้ลงชื่อเข้าใช้อีกครั้งและค้นหาการดำเนินการยกเลิกของคำขอที่รอดำเนินการ ติดต่อฝ่ายสนับสนุนทันทีหากคุณไม่สามารถเข้าถึงได้

อย่าสร้างคำขออื่นโดยไม่ทราบสถานะของคำขอก่อนหน้า ข้อผิดพลาดของเครือข่ายไม่ได้พิสูจน์ว่าเซิร์ฟเวอร์ไม่สามารถรับข้อผิดพลาดดังกล่าวได้

5. ขอลบนอกแอป

คุณสามารถใช้แบบฟอร์มนี้ได้โดยไม่ต้องติดตั้งใหม่หรือลงชื่อเข้าใช้แอป หลังจากได้รับแล้ว ฝ่ายสนับสนุนจะต้องตรวจสอบยืนยันว่าคุณเป็นเจ้าของบัญชีก่อนที่จะดำเนินการ การรู้อีเมล/รหัสประจำตัวบ้านไม่ได้อนุญาตให้ลบข้อมูลของผู้อื่นได้

ข้อมูลที่ส่ง ที่อยู่ IP และข้อมูลเบราว์เซอร์จะได้รับการประมวลผลเพื่อรับ การตรวจสอบ และป้องกันการละเมิดตามที่อธิบายไว้ใน นโยบายความเป็นส่วนตัว. อย่าป้อนรหัสผ่าน, PIN, รหัสแบบใช้ครั้งเดียวหรือเอกสารระบุตัวตนที่ละเอียดอ่อนในหมายเหตุ

ตัวอย่างเช่น: ลบบัญชีของฉันและตรวจสอบภาพถ่ายส่วนตัวหรือรายการไดอารี่ที่เหลืออยู่ อย่าร้องขอให้ลบบัญชีของบุคคลอื่น

หากการส่งล้มเหลวให้ส่งอีเมล support@soullocket.pro.vn จากอีเมลบัญชีของคุณเมื่อเป็นไปได้ เก็บ ID คำขอไว้เพื่อสอบถามเกี่ยวกับความคืบหน้า “บันทึก” ไม่ได้หมายความว่า “ถูกลบ”
