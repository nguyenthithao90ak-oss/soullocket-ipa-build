문서 버전 2026-09-28 번역. 표현이 명확하지 않거나 언어마다 다른 경우 지원팀에 문의하세요.

1. 계정을 확인하세요 2. 단독으로 사용하거나 페어링하여 사용하세요. 3. 기기를 보호하고 권한을 부여하세요 4. 데이터가 저장되는지 확인 5. 개인화

1. 계정을 확인하세요

설정을 열고 이메일, 이름, 사진 및 현재 집을 확인하세요. 기기를 변경할 때는 기존 계정을 사용하세요. 데이터를 복구하기 위해 새 계정을 만들지 마십시오.

읽기 개인 정보 보호 정책 그리고 쿠키 선택 제한. “Essential”을 선택한다고 해서 모든 SDK가 비활성화되는 것은 아닙니다.

2. 단독으로 사용하거나 페어링하여 사용하세요.

앱만 단독으로 사용해도 됩니다. 연결하려면 여세요. 파트너와 연결: 한 사람이 초대장/QR을 작성하고, 다른 사람이 이를 입력/스캔하여 승인을 기다립니다. 커플 모드는 계정을 자동으로 페어링하지 않습니다.

먼저 백업하세요. 코드를 입력한 사람은 작성자의 집으로 이동합니다. 이전 하우스의 데이터는 자동으로 병합되지 않으며 구성원이 없는 이전 하우스는 정리될 수 있습니다. 그런 다음 아바타와 연결 날짜를 모두 확인하세요. 참조 페어링 가이드.

3. 기기를 보호하고 권한을 부여하세요

다른 액세스 잠금을 원할 경우 앱 PIN 및 생체 인식을 활성화하세요. 귀하가 사용하는 기능에 대해서만 카메라, 마이크, 위치, 건강 또는 알림 권한을 부여하십시오. 운영 체제 설정에서 이를 취소할 수 있습니다.

백그라운드 위치/수면 공유를 활성화한 경우 집에 있는 사람 중 누가 상태를 볼 수 있는지 확인하세요. PIN 자체는 다른 회원의 권한을 제한하지 않습니다.

4. 데이터가 저장되는지 확인

  1. Diary → Reflections를 열고 짧은 메시지를 입력한 후 저장하세요.
  2. 성공할 때까지 기다렸다가 목록으로 돌아가서 확인하세요.
  3. 추억 사진을 추가하고 업로드가 완료될 때까지 기다린 후 다시 열어보세요.
  4. 오류가 발생하면 초안을 보관하고 지원팀에 문의하세요. 데이터가 동기화되었는지 확실하지 않은 경우 제거하거나 저장소를 지우거나 다시 페어링하지 마십시오.

5. 개인화

사용 가능한 설정 섹션을 사용하여 모양, 기념일, 음악 또는 바로가기를 조정하세요. 공유할 자격이 있는 콘텐츠/링크만 사용하십시오. 외부 콘텐츠는 별도의 공급자에 연결될 수 있습니다.

중요한 콘텐츠의 사본을 보관하세요. 도움이 필요하면 열어보세요. 지원; 서비스 사용을 중지하고 데이터를 삭제하려면 계정/하우스 삭제 프로세스.
