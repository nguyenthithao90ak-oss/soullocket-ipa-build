1. アカウントと共有スペース

アカウントはサインインとアクセスの管理に使用されます。ハウスは、プロフィール、日記、思い出、共有コンテンツを保持するスペースです。このアプリは自分で使用することもできます。接続する、開く 設定 → パートナーと接続する 招待状を作成、入力、またはスキャンします。

ペアリングされると、画面には両方のアバター、名前、接続日が表示されます。この画面の外にあるショートカットには、アバターとペアリング ステータスの両方が表示されます。カップル モードを選択しても、2 つのアカウントのペアリングが置き換えられるわけではありません。

2. 機能グループ

  • ホーム: アバター、曜日カウンター、プレゼンス、ショートカット。
  • 日記/思い出: 個人的な感想、保存された写真、同期されたコンテンツ。
  • チャット/コミュニティ: 各機能の範囲内のコンテンツ、対話、共有。
  • アプリのバージョンで利用できるユーティリティ、ゲーム、クリエイティブ コンテンツ。
  • 設定、セキュリティ、サポート、プライバシーの選択。

可用性は、プラットフォーム、バージョン、デバイスの権限、構成によって異なります。ソース コード内の機能ファイルは、その機能がすべてのリリースで有効になっているか、動作することを意味するものではありません。

3. データとインフラストラクチャ

SoulLocket は、認証、データベース、通知に Firebase を使用し、関連するファイルとサービス フローに Cloudflare R2/Workers を使用します。サーバー データに加えて、デバイスはドラフト、キャッシュ、ダウンロードを保持する場合があります。

あなたのハウスパートナーは、機能に従って共有コンテンツにアクセスできます。 PIN ロック自体は、共有コンテンツを自分だけが閲覧できるようにするものではありません。ペアリングする前に、古い House の警告を読み、保持する必要があるものはすべてバックアップしてください。

4. 知っておくべき制限事項

SoulLocket は、絶対的なセキュリティ、中断のない操作、すべてのデータの回復を保証するものではありません。緊急サービスや専門家のアドバイスに代わるものではありません。 AI コンテンツ、地図、プレゼンス ステータスは不正確または遅延する可能性があります。

SoulLocket を秘密裏に追跡したり、他人に強要したり、使用する資格のないデータを共有したりするために使用しないでください。
