1. 帳戶和共享空間

您的帳戶用於登入和管理存取。房子是保存個人資料、日記、記憶和分享內容的空間。您可以自行使用該應用程式；連接、打開 設定 → 與您的伴侶聯繫 建立、輸入或掃描邀請。

配對後，螢幕會顯示頭像、姓名和連線日期；該螢幕外的捷徑顯示頭像和配對狀態。選擇情侶模式並不取代配對兩個帳號。

2. 功能組

  • 首頁：頭像、日計數器、狀態和捷徑。
  • 日記/回憶：個人感想、保存的照片和同步內容。
  • 聊天/社群：每個功能範圍內的內容、互動和分享。
  • 您的應用程式版本中提供實用程式、遊戲和創意內容。
  • 設定、安全、支援和隱私選擇。

可用性取決於平台、版本、設備權限和配置。原始碼中的功能文件並不意味著該功能已啟用或在每個版本中都有效。

3. 數據和基礎設施

SoulLocket 使用 Firebase 進行驗證、資料庫和通知，並使用 Cloudflare R2/Workers 進行相關檔案和服務流程。除了伺服器資料之外，設備還可以保存草稿、快取和下載。

您的House合作夥伴可以根據功能存取共享內容； PIN 鎖定本身並不會使共享內容僅對您可見。在配對之前，請閱讀舊的 House 警告並備份您需要保留的所有內容。

請參閱 隱私權政策 對於提供者、資料和您的權利。

4. 需要了解的限制

SoulLocket不保證每個資料的絕對安全、不間斷運作或復原。它不能取代緊急服務或專業建議。 AI 內容、地圖和狀態可能不準確或延遲。

請勿使用 SoulLocket 秘密追蹤他人、脅迫他人或分享您無權使用的資料。
