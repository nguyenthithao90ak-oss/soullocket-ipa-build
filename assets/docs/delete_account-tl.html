Tanggalin ang Iyong SoulLocket Account at Data

Ang pagtanggal sa iyong sign-in account at pagtanggal ng nakabahaging data ng House ay magkaibang mga pagkilos. Ang pagsusumite ng kahilingan ay hindi nangangahulugan na ang data ay tinanggal na.

1. Piliin ang tamang saklaw

  • Pagtanggal ng account: humihiling ng pagsasara ng iyong kasalukuyang sign-in account at pangangasiwa ng kaugnay na data. Hindi nito awtomatikong tinatanggal ang buong Bahay ng iyong partner.
  • Pagtanggal ng data ng breakup / House: humihiling ng paglilinis ng nakabahaging espasyo at maaaring makaapekto sa data ng parehong tao. Hindi nito mismo tinatanggal ang mga sign-in account.
  • Pagtanggal ng indibidwal na nilalaman: gamitin ang may-katuturang diary, larawan, post o utility sa pagtanggal ng aksyon kung gusto mo lang alisin ang bahagi ng iyong nilalaman.
I-export/i-save ang anumang kailangan mo bago kumpirmahin. Hindi pinapalitan ng pag-uninstall o pag-sign out ang isang kahilingan sa pagtanggal. Hindi rin awtomatikong kinakansela ng pagtanggal ng account ang mga subscription sa isang tindahan ng pagbabayad.

2. Mga panahon ng paghihintay sa kasalukuyang daloy

Ang eksaktong oras ay ibinalik ng server at ipinapakita sa app. Inilalarawan ng mga tuldok sa ibaba ang kasalukuyang processing code, hindi isang garantiya na ang bawat kopya ay tatanggalin sa isang tiyak na minuto.

Walang garantisadong pagbawi pagkatapos ng permanenteng pagtanggal.

3. Pinangangasiwaan ang data at kasalukuyang mga limitasyon

Nililinis ng kasalukuyang daloy ng pagtanggal ng account ang profile ng account, mga link ng membership, mga token ng presensya/device at ilang kahilingan/ulat sa suporta na naka-link sa UID, pagkatapos ay tinatanggal ang authentication account. Nililinis ng daloy ng pagtanggal ng Kamara ang Kamara, pampublikong profile, mga sangay ng mensahe, mga abiso, mga kaibigan, GPS, mga imbitasyon at data na nauugnay sa Bahay sa loob ng ipinatupad na saklaw nito.

Huwag ipagpalagay na ang pagtanggal ng account ay sabay-sabay na nag-aalis ng bawat lumang piraso ng nilalaman. Ang nilalaman ng Shared House, Cloudflare R2 media, ilang data ng Firestore o iba pang mga tala ay maaaring mangailangan ng karagdagang pagsusuri at pangangasiwa. Ang kasalukuyang mekanismo ay hindi sapat upang mangako ng kumpletong paglilinis ng lahat ng mga tindahang ito. Tukuyin ang anumang natitirang personal na data na gusto mong tanggalin sa iyong kahilingan sa suporta.

Ang mga na-download na kopyang hawak ng iba, mga screenshot, at mga pag-export ng device ay hindi maaaring malayuang maalala. Ang data na napanatili para sa mga legal na obligasyon, pangangasiwa sa pandaraya o mga hindi pagkakaunawaan ay dapat na limitado; maaari mong itanong kung ano ang nananatili, bakit at gaano katagal. Walang pangako na ang lahat ng nilalaman ng komunidad ay awtomatikong nagiging anonymous.

4. Mga aksyon sa app

  1. Mag-sign in sa tamang account, buksan Mga setting at hanapin Pagtanggal ng Account at Data o Paghiwalay / Tanggalin ang Data.
  2. Basahin ang apektadong saklaw at mga hakbang sa pagkumpirma. Kasama sa pagtanggal ng account ang email/one-time-code na pag-verify; magpasok lamang ng mga code sa opisyal na app, hindi sa mga mensaheng sinusuportahan.
  3. Suriin ang mensahe ng tagumpay at nakaiskedyul na oras. Maaaring i-sign out ka ng app pagkatapos gumawa ng kahilingan sa pagtanggal ng account.
  4. Upang mag-withdraw bago ang deadline, mag-sign in muli at hanapin ang aksyon sa pagkansela ng nakabinbing kahilingan; makipag-ugnayan kaagad sa suporta kung hindi mo ito ma-access.

Huwag gumawa ng isa pang kahilingan nang hindi nalalaman ang katayuan ng nakaraang kahilingan. Ang isang error sa network ay hindi nagpapatunay na nabigo ang server na matanggap ito.

5. Humiling ng pagtanggal sa labas ng app

Magagamit mo ang form na ito nang hindi muling nag-i-install o nagsa-sign in sa app. Pagkatapos matanggap ito, dapat i-verify ng suporta na pagmamay-ari mo ang account bago kumilos; ang pag-alam sa isang email/House ID ay hindi nagpapahintulot sa pagtanggal ng data ng ibang tao.

Ang isinumiteng impormasyon, IP address at impormasyon ng browser ay pinoproseso para sa pagtanggap, pagpapatunay at anti-aabuso gaya ng inilarawan sa Patakaran sa Privacy. Huwag maglagay ng mga password, PIN, isang beses na code o sensitibong dokumento ng pagkakakilanlan sa mga tala.

Halimbawa: tanggalin ang aking account at suriin ang natitirang mga personal na larawan o mga entry sa talaarawan. Huwag humiling ng pagtanggal ng account ng ibang tao.

Kung nabigo ang pagsusumite, mag-email support@soullocket.pro.vn mula sa iyong account email kapag posible. Panatilihin ang request ID para magtanong tungkol sa pag-unlad; Ang "naitala" ay hindi nangangahulugang "tinanggal".
