刪除您的 SoulLocket 帳戶和數據

1.選擇正確的範圍

  • 帳戶刪除： 請求關閉您目前的登入帳戶並處理相關資料。它不會自動刪除您伴侶的整個房屋。
  • 分手/房屋資料刪除： 請求清理共享空間並可能影響雙方的資料。它本身不會刪除登入帳戶。
  • 個別內容刪除： 如果您只想刪除部分內容，請使用相關的日記、照片、貼文或實用程式刪除操作。
在確認之前匯出/儲存您需要的任何內容。卸載或登出並不能取代刪除請求。帳戶刪除也不會自動取消支付商店的訂閱。

2. 目前流程中的等待時間

確切的時間由伺服器傳回並顯示在應用程式中。下面的時間段描述了目前的處理程式碼，並不能保證每個副本都在精確的分鐘被刪除。

請求調度
沒有有效識別的房屋即可刪除帳戶安排在請求後 3 天。
刪除 House 帳戶目前的流程設定了 30 天的等待時間，即使眾議院還沒有兩名議員。如果其他符合資格的會員確認，時間將重設為確認後 3 天。
單模式刪除房屋預定3天後。
分手/情侶之家刪除等待其他成員的確認或 30 天的等待期限。轉為預定狀態後，刪除前還有一天的時間。
應用程式外部請求建立支援請求以進行驗證和處理，而不是立即刪除。不承諾7天內自動完成。支援人員需要在驗證後傳達適當的進度/時間。

對於共享房屋，請求者無法透過切換到登入相同帳戶的其他裝置進行自我確認。在截止日期之前和處理開始之前，如果介面仍然允許，您可以取消/撤回請求。永久刪除後不保證恢復。

3. 處理的資料和目前限制

目前帳戶刪除流程會清理帳戶設定檔、成員資格連結、狀態/裝置令牌和一些 UID 連結的支援請求/報告，然後刪除身分驗證帳戶。 House刪除流程在其實施範圍內清理House、公開資料、訊息分支、通知、朋友、GPS、邀請和House相關資料。

不要假設刪除帳戶會同時刪除所有舊內容。 共享之家內容、Cloudflare R2 媒體、某些 Firestore 資料或其他記錄可能需要額外審查和處理。目前的機制不足以承諾徹底清理所有這些商店。在支援請求中指定您想要刪除的任何剩餘個人資料。

他人持有的下載副本、螢幕截圖和裝置導出無法遠端呼叫。出於法律義務、詐欺處理或爭議而保留的資料必須受到限制；您可能會問保留什麼、為什麼以及保留多長時間。不承諾所有社群內容都會自動變成匿名。

4. 應用程式中的操作

  1. 登入正確的帳戶，打開 設定 並找到 帳戶和資料刪除 或 分解/刪除數據.
  2. 請閱讀受影響的範圍和確認步驟。帳戶刪除包括電子郵件/一次性代碼驗證；僅在官方應用程式中輸入代碼，而不是在支援訊息中輸入代碼。
  3. 檢查成功訊息和預定時間。該應用程式可能會在建立帳戶刪除請求後將您登出。
  4. 若要在截止日期之前撤回，請重新登入並尋找待處理要求的取消操作；如果您無法訪問，請立即聯絡支援人員。

在不知道前一個請求的狀態的情況下，請勿建立另一個請求。網路錯誤並不能證明伺服器無法接收它。

5.應用程式外請求刪除

您無需重新安裝或登入應用程式即可使用此表單。收到後，支援人員必須在採取行動之前驗證您是否擁有該帳戶；知道電子郵件/房屋 ID 並未授權刪除他人的資料。

提交的資訊、IP 位址和瀏覽器資訊將按照以下規定處理，以進行接收、驗證和反濫用 隱私權政策。請勿在筆記中輸入密碼、PIN、一次性代碼或敏感身分證明文件。

例如：刪除我的帳戶並查看剩餘的個人照片或日記。請勿要求刪除他人的帳戶。
