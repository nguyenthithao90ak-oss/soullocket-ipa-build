Tamang account at Bahay

1. Ang account ang gamit sa pag-sign in. Ang Bahay (House) ay espasyo ng data; maaaring makita ng mga miyembro ang ibinahaging nilalaman ayon sa feature.

2. Sa Settings, tingnan ang account, pangalan/avatar, Bahay at petsa. Sa bagong device gamitin ang parehong account at paraan ng pag-sign in. Huwag gumawa ng bagong Bahay para hanapin ang lumang data.

3. Bawat tao ay may sariling account. Huwag ibahagi ang password, OTP o recovery code. Kung may nawawalang data, suriin ang account/Bahay at koneksyon. Itago ang drafts; huwag mag-clear ng data o mag-uninstall bago matapos ang sync.

I-save ang unang alaala

1. Sa Diary, ang posts ay para sa sulat/damdamin; Memories para sa larawan/video. Piliin ang pagsulat o pagdagdag sa tamang seksyon.

2. Piliin ang nilalaman at kumpirmahin. Payagan lang ang larawan/camera kung kailangan. Maaaring makita ito ng kasama sa Bahay; ang screen lock ay hindi only-me setting.

3. Hintayin ang kumpirmasyong na-save at hanapin ang bagong item sa listahan. Ang uploading, pending o lokal na kopya ay hindi patunay na tapos na ang sync.

4. Kung pumalya, itago ang orihinal, suriin ang koneksyon at gamitin ang Retry kung mayroon. Tingnan muna ang listahan bago muling ipadala para maiwasan ang doble. Huwag mag-uninstall dahil sa hindi tapos na upload. Pindutin nang matagal ang alaala para piliin at pamahalaan.

Magpares kapag handa na

Bawat isa ay mag-sign in sa sariling account; huwag magbahagi ng password. Opsyonal ang pagpares.

Mananatili ang Bahay ng gumawa ng code. Bago ipasok at kumpirmahin, basahin ang babala sa data ng sasali; huwag ipalagay na awtomatikong pagsasamahin lahat ng data ng dalawang Bahay.

Gamitin ang 12-digit na imbitasyon o pairing QR, hindi sign-in/lipat-device QR. Humingi ng bagong code kung expired; bumalik sa Pairing kung maling uri ng QR. Ang naghihintay o tinanggihan ay hindi konektado. Pagkatapos aprubahan, tingnan ang dalawang miyembro sa Pairing.

1. Create an invitation

Create a time-limited 12-digit code or QR, then share it through a channel you trust.

2. Your partner joins

Your partner opens Pairing, scans the QR or enters all 12 digits to send a request.

3. You approve

Confirm the sender in your invitation list, then select Accept.

4. Use your shared space

Once connected, you can share journals, memories, and couple features together.

GPS & privacy

Location while using the app is enough for the map. When sharing, your coordinates and movement history sync to your home. Background access is not required to browse the map; only choose “Allow all the time” if you want to use sharing while away from the app. You can change or revoke access in device Settings.

Magkaiba ang permiso at GPS. Para ihinto ang bagong lokasyon, bawiin ang location access ng SoulLocket sa device/site settings. Opsyonal ang background access. Hindi nito binubura ang na-sync na lokasyon/history; tingnan ang data rights o support.

Allow location in this site’s permissions, check device location, then try again. Your browser needs HTTPS or localhost; background location sharing is not supported here.

Password, PIN at lihim na vault

• Ang password sa pag-sign in ay para sa account; gamitin ang account recovery kung nakalimutan.

• Ang PIN ng app/diary ay kandado ng interface. Hindi kapalit ng password o garantiya ng end-to-end encryption ng lahat ng nilalaman. Paganahin lang ang kailangang saklaw sa Settings.

• May sariling susi at recovery code ang vault. Itago ang code sa ligtas na lugar sa labas ng app; huwag ipadala sa support. Kung nalimutan ang susi, gamitin ang naitabi mong vault code.

• Ang reset ay hindi pagbawi ng larawan: kailangan ng email OTP at 24 oras bago burahin ang lihim na larawan, encrypted notes at susi. Maaaring bawiin habang naghihintay ayon sa screen. Basahin ang babala; huwag mag-reset para lang sumubok.

Customize counting rings

1. Sa Home piliin ang Customize counter o pindutin nang matagal para sa estilo, kulay at laki.

2. Hiwalay ang petsa ng simula: tapikin ang petsa/counter ayon sa layout o tingnan sa Settings. Hindi binabago ng estilo ang anibersaryo.

3. Tingnan ang preview at pindutin ang Save kung mayroon; tingnan sa Home ang agarang pagbabago. Avatar/frame ay mula sa avatar o Settings, hindi sa background ng counter.

4. Kung wala ang pagbabago, suriin ang Bahay, na-save na opsyon at error. Hindi kailangan ng bagong Bahay.

Widgets sa home screen

Hindi awtomatikong idinadagdag ng preview ang widget sa telepono. Makikita ito ng ibang may hawak ng device; pag-isipan ang pagpapakita ng larawan/diary.

Android

Android: Settings → Widget, pumili at i-save/i-sync, saka idagdag at kumpirmahin sa launcher. Kung walang automatic pin, pindutin nang matagal ang home screen → Widgets → SoulLocket at i-drag sa bakanteng lugar.

iOS

On iOS, long press the home screen and select "+" to add the SoulLocket widget.

Web

Hindi nagdadagdag ng system widget ang Web/desktop na ito. Gamitin ang Android o iOS app sa telepono.

Kung luma ang widget, buksan ang tamang account/Bahay, suriin ang koneksyon, i-save muli at mag-refresh sa Widget. Tingnan ang home screen; ang request ay hindi patunay na nailagay na ng launcher.

Utilities

Hanapin ang tool sa pangalan o maikling salita gaya ng “notes”. Hiwalay ang paghahanap ng gabay sa center na ito.

Depende ang tools sa solo/couple mode, platform at release; ang wala ay hindi laging error. Hindi iniaalok ang nakatagong experimental features.

Basahin ang paglalarawan at saklaw ng sharing bago mag-save. Payagan ang notification, camera o mic kapag kailangan lang; puwedeng tumanggi at baguhin sa device settings.

Pagbawi at pag-aayos ng problema

1. Nakalimutang password: piliin ang recovery sa sign-in at ilagay ang email o House code ayon sa screen. Magkaiba ang verification; tingnan ang spam at expiration ng code/link. Ang pairing invite ay hindi House code.

2. Nawalang data/bagong device: suriin ang account, sign-in method at Bahay; hintayin ang sync, tingnan ang error/drafts at mag-export ng kopya kung sinusuportahan. Huwag gumawa ng Bahay para maghanap ng lumang data.

3. Kontakin ang support mula Settings/Updates: bersyon, screen, oras, hakbang at error, nakatago ang pribado. Huwag ipadala ang password, OTP, PIN, recovery/invite code o eksaktong lokasyon.

Suriin ang koneksyon at account, saka subukan muli. Huwag i-uninstall o burahin ang data ng app kung may mga draft na hindi pa naka-sync. Kontakin ang suporta kung nagpapatuloy ang problema.
