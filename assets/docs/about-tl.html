1. Mga account at shared space

Ginagamit ang iyong account para mag-sign in at pamahalaan ang access. Ang Bahay ay ang puwang na may hawak na mga profile, talaarawan, alaala at nakabahaging nilalaman. Maaari mong gamitin ang app sa iyong sarili; para kumonekta, buksan Mga Setting → Kumonekta sa iyong partner upang lumikha, magpasok o mag-scan ng isang imbitasyon.

Kapag naipares na, ipinapakita ng screen ang parehong mga avatar, pangalan at petsa ng koneksyon; ang shortcut sa labas ng screen na ito ay nagpapakita ng parehong mga avatar at ang nakapares na katayuan. Hindi pinapalitan ng pagpili ng Couple mode ang pagpapares ng dalawang account.

2. Mga pangkat ng tampok

  • Tahanan: mga avatar, day counter, presensya at mga shortcut.
  • Mga talaarawan/alaala: mga personal na pagmuni-muni, naka-save na mga larawan at naka-synchronize na nilalaman.
  • Chat/komunidad: content, mga pakikipag-ugnayan at pagbabahagi sa loob ng saklaw ng bawat feature.
  • Available ang mga utility, laro, at creative na content sa bersyon ng iyong app.
  • Mga setting, seguridad, suporta at mga pagpipilian sa privacy.

Ang availability ay depende sa platform, bersyon, mga pahintulot ng device at configuration. Ang isang feature file sa source code ay hindi nangangahulugan na ang feature ay pinagana o gumagana sa bawat release.

3. Data at imprastraktura

Gumagamit ang SoulLocket ng Firebase para sa authentication, mga database at notification, kasama ng Cloudflare R2/Workers para sa mga nauugnay na file at mga daloy ng serbisyo. Bukod sa data ng server, maaaring may mga draft, cache, at download ang mga device.

Maaaring i-access ng iyong kasosyo sa Bahay ang nakabahaging nilalaman ayon sa tampok; ang isang PIN lock ay hindi gumagawa ng nakabahaging nilalaman na nakikita lamang sa iyo. Bago ipares, basahin ang lumang babala ng Bahay at i-back up ang anumang kailangan mong panatilihin.

Tingnan ang Patakaran sa Privacy para sa mga provider, data at iyong mga karapatan.

4. Mga limitasyong dapat malaman

Hindi ginagarantiya ng SoulLocket ang ganap na seguridad, walang patid na operasyon o pagbawi ng bawat piraso ng data. Hindi nito pinapalitan ang mga serbisyong pang-emergency o propesyonal na payo. Ang nilalaman ng AI, mga mapa at katayuan ng presensya ay maaaring hindi tumpak o naantala.

Huwag gumamit ng SoulLocket para lihim na subaybayan ang mga tao, pilitin ang iba o ibahagi ang data na hindi mo karapat-dapat na gamitin.
