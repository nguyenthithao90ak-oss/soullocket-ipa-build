1. Mga teknolohiyang ginamit

Maaaring gumamit ang web ng cookies, localStorage, sessionStorage at IndexedDB. Gumagamit ang app ng SharedPreferences, secure na imbakan ng pagpapatotoo, mga lokal na database at mga cache ng imahe/file. Ang mga ito ay hindi lahat ng parehong uri ng cookie, ngunit maaari silang lahat ay mag-imbak ng data sa iyong device.

Ang mga pahina ng patakarang ito ay hindi nag-e-embed ng advertising o Analytics code. Ang form ng pagtanggal ng account ay nagpapadala lamang ng data kapag isinumite mo ito; ang pangunahing app at iba pang mga pahina ng nilalaman ay may hiwalay na gawi sa pagproseso.

3. Ano ang ibig sabihin ng "Mahalaga" at "Lahat".

Sa bagong pagsasama, dini-disable ng “Essential” ang pagkolekta ng Analytics/Crashlytics at bina-block nito ang pagsisimula at paglo-load ng ad sa pamamagitan ng app. Pinahihintulutan ng "Lahat" ang mga opsyonal na SDK na ito; ang mga ad ay dapat pa ring payagan ng Google UMP at sundin ang mga pahintulot ng operating system. Itinatala ng app ang pagpipilian, oras at bersyon ng dokumento sa device; Ang mga legacy na pagpipilian na walang bersyon ay nangangailangan ng kumpirmasyon muli.

Bina-block ng withdrawal ang mga bagong kahilingan at inaalis ang mga na-load na ad sa app; hindi nito maalala ang data na naipadala na o mga koneksyon na nagpapatuloy. Maaaring panatilihing lokal ng mga native SDK ang mga ulat ng pag-crash; humihiling ang app na tanggalin ang mga hindi naipadalang ulat bago i-enable ang pagkolekta. Maaaring hindi kasama sa mga mas lumang bersyon ng app ang mga kontrol na ito.

Hindi ino-off ng “Essential” ang pag-sign in, pag-synchronize, mga transaksyon, kaligtasan ng system o bawat koneksyon ng third-party. Hindi nito pinapalitan ang mga pahintulot sa sensitibong data, mga pahintulot sa operating system o hiwalay na pahintulot ng ad.

4. Mga nauugnay na provider

Firebase/Google Sign-In, Facebook kapag ginamit para sa pag-sign-in, ang Google Mobile Ads/AdMob, mga platform ng pagbabayad, mga serbisyo sa mapa at imprastraktura ng Cloudflare ay maaaring gumamit ng mga token, cache o teknikal na estado para sa kanilang mga feature. Maaaring kumonekta sa mga provider ang naka-embed na content, mga font at external na file kapag na-load.

Ang mga kategorya ng data, layunin at saklaw ng pagbabahagi ay inilalarawan sa Patakaran sa Privacy. Hindi pinapalitan ng mga patakaran ng provider ang responsibilidad ng SoulLocket para sa mga pagsasama nito.

5. Pamamahala at pag-withdraw ng mga pagpipilian

  • Buksan ang Mga Setting → Mga pagpipilian sa privacy upang lumipat sa pagitan ng "Mahalaga" at "Lahat". Piliin ang "Mahalaga" para bawiin ang pahintulot para sa opsyonal na pangkat ng SDK nang hindi kine-clear ang data ng app. Binubuksan ng mga pagpipilian sa privacy ng ad ang mga pagpipilian sa Google UMP kung saan naaangkop.
  • Pamahalaan ang lokasyon, camera, mikropono, notification, kalusugan at mga pahintulot sa pag-advertise/pagsubaybay sa iyong mga setting ng operating system. Ang mga available na kontrol ay nag-iiba ayon sa device.
  • Gamitin ang mga setting ng privacy ng iyong browser upang siyasatin/tanggalin ang data ng website. Maaaring tapusin ng pag-block ng mahahalagang data ang iyong session sa pag-sign in o makagambala sa mga feature.
  • Makipag-ugnayan sa suporta tungkol sa mga karapatan sa privacy kapag ang interface ay kulang sa kinakailangang pagkilos. Ang pag-clear sa data ng app ay hindi dapat ituring bilang ang tanging paraan upang bawiin ang pahintulot.

6. Pagpapanatili at mga epekto ng pag-clear ng data

Maaaring mag-expire ang data ng session sa pagtatapos ng isang session; ang mga kagustuhan at mga lokal na database ay maaaring manatili hanggang sa i-clear mo ang data ng app/website. Ang mga cache ay may sariling buhay at maaaring ma-download muli. Hindi ginagarantiya ng pag-sign out ang pag-aalis ng lahat ng cache, pag-download o pag-backup ng device.

I-export o i-synchronize ang hindi na-save na data bago i-clear ang storage. Ang pag-uninstall ng app, pagtanggal ng cookies o hindi pagpapagana ng mga pahintulot ay hindi nagtatanggal ng iyong account, data ng server o subscription. Tingnan ang Gabay sa Pagtanggal ng Account at Data.

7. Mga update at contact

Ang dokumentong ito ay nangangailangan ng kaukulang mga update kapag nagbago ang mga mekanismo ng storage, SDK o mga pagpipilian. Magpadala ng mga tanong sa support@soullocket.pro.vn, kabilang ang platform at bersyon ng app; huwag magpadala ng mga password, PIN o isang beses na code.
