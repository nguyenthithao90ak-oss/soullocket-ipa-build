删除 SoulLocket 账号与数据

删除登录账号与删除共享小屋数据是不同的操作。提交请求不表示数据已经删除。

1. 选择正确的范围 2. 当前流程的等待期 3. 处理的数据与当前限制 4. 应用内操作 5. 在应用外请求删除

1. 选择正确的范围

  • 删除账号： 请求关闭你当前用于登录的账号，并处理相关数据。这不会自动删除另一半的整个小屋。
  • 分手／删除小屋数据： 请求清理共享空间，可能影响双方的数据。此操作本身不删除登录账号。
  • 删除单项内容： 如果只想删除部分内容，请使用对应日记、照片、帖子或工具中的删除操作。
确认前请导出或保存需要保留的内容。卸载应用或退出登录不能替代删除请求。删除账号也不会自动取消支付商店中的订阅。

2. 当前流程的等待期

确切时间由服务器返回并显示在应用中。以下期限描述当前处理代码的行为，不保证所有副本都在某个精确时刻删除。

请求类型时间安排
未识别到有效小屋时删除账号安排在提出请求3天后执行。
账号关联小屋时删除账号当前流程设置30天等待期，即使小屋尚未有两位成员也一样。如果另一位符合条件的成员确认，执行时间将重新设为该确认后的3天。
单人模式下删除小屋安排在3天后执行。
分手／删除情侣小屋等待另一位成员确认或30天等待期届满。转入已安排状态后，还需再等1天才删除。
应用外请求创建支持请求以便核实和处理，不会立即删除。没有承诺在7天内自动完成。核实后，支持团队需要说明适当的进度和时间安排。

对于共享小屋，请求人不能通过换用另一台登录相同账号的设备来替另一位成员确认。截止时间前且处理尚未开始时，如果界面仍允许，你可以取消或撤回请求。永久删除后不保证能恢复。

3. 处理的数据与当前限制

当前账号删除流程会清理账号资料、成员关联、在线状态和设备令牌，以及部分关联 UID 的支持请求或举报，然后删除身份验证账号。小屋删除流程会在已实现的范围内清理小屋、公开资料、消息分支、通知、好友、GPS、邀请及与小屋关联的数据。

请勿认为删除账号会同时删除所有历史内容。 共享小屋内容、Cloudflare R2 媒体文件、部分 Firestore 数据或其他记录，可能需要进一步审查和处理。当前机制不足以承诺彻底清理所有这些存储。请在支持请求中说明仍需删除的个人数据。

无法远程收回他人已下载的副本、截图或设备导出文件。因法律义务、欺诈处理或争议而保留的数据必须有所限制；你可以询问保留了什么、为何保留及保留多久。没有承诺所有社区内容都会自动匿名化。

4. 应用内操作

  1. 登录正确的账号，打开 设置 并找到 删除账号与数据 或 分手／删除数据.
  2. 阅读受影响的范围和确认步骤。删除账号包括邮箱或一次性验证码验证；只在官方应用中输入验证码，不要通过消息发送给支持团队。
  3. 查看成功提示及安排的执行时间。创建账号删除请求后，应用可能会让你退出登录。
  4. 如需在截止时间前撤回，请重新登录，查找待处理请求的取消操作；如果无法访问，请及时联系支持团队。

未确认先前请求的状态前，请勿再次创建请求。网络错误不能证明服务器没有收到请求。

5. 在应用外请求删除

无需重新安装或登录应用即可使用此表单。收到请求后，支持团队必须先核实账号属于你，再采取措施；知道某人的邮箱或小屋 ID 并不代表有权删除其数据。

提交的信息、IP 地址及浏览器信息将用于接收请求、核实身份和防滥用，具体见 隐私政策。请勿在备注中填写密码、PIN、一次性验证码或敏感身份证件。

例如：删除我的账号，并检查剩余的个人照片或日记。请勿请求删除他人的账号。

如果提交失败，请发送邮件至 hotroviethoangdev.lo.ve@gmail.com ，并尽量使用账号绑定的邮箱发送。请保留请求编号以便查询进度；“已记录”不等于“已删除”。
