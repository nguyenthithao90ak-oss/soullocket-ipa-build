Kebijakan Cookie dan Penyimpanan Lokal

Membedakan penyimpanan yang diperlukan untuk layanan dari pilihan pengukuran, periklanan, dan privasi. Dokumen ini mencakup SoulLocket pada perangkat, web, dan konten tersemat.

1. Teknologi yang digunakan

Web mungkin menggunakan cookie, localStorage, sessionStorage, dan IndexedDB. Aplikasi ini menggunakan SharedPreferences, penyimpanan autentikasi yang aman, database lokal, dan cache gambar/file. Ini bukan jenis cookie yang sama, namun semuanya mungkin menyimpan data di perangkat Anda.

Halaman kebijakan ini tidak menyematkan iklan atau kode Analytics. Formulir penghapusan akun mengirimkan data hanya ketika Anda mengirimkannya; aplikasi utama dan halaman konten lainnya memiliki perilaku pemrosesan terpisah.

3. Apa yang dimaksud dengan “Esensial” dan “Semua”.

Dalam integrasi baru, “Essential” menonaktifkan pengumpulan Analytics/Crashlytics dan memblokir inisialisasi dan pemuatan iklan melalui aplikasi. “Semua” mengizinkan SDK opsional ini; iklan harus tetap diizinkan oleh Google UMP dan mengikuti izin sistem operasi. Aplikasi ini mencatat pilihan, waktu dan versi dokumen pada perangkat; pilihan lama tanpa versi memerlukan konfirmasi lagi.

Penarikan memblokir permintaan baru dan menghapus iklan yang dimuat di aplikasi; ia tidak dapat mengingat data yang telah dikirim atau koneksi yang sedang berlangsung. SDK asli mungkin menyimpan laporan kerusakan secara lokal; aplikasi meminta penghapusan laporan yang belum terkirim sebelum mengaktifkan pengumpulan. Versi aplikasi yang lebih lama mungkin tidak menyertakan kontrol ini.

“Essential” tidak mematikan proses masuk, sinkronisasi, transaksi, keamanan sistem, atau setiap koneksi pihak ketiga. Ini tidak menggantikan izin data sensitif, izin sistem operasi, atau izin iklan terpisah.

4. Penyedia terkait

Firebase/Login Google, Facebook saat digunakan untuk login, Iklan Seluler Google/AdMob, platform pembayaran, layanan peta, dan infrastruktur Cloudflare dapat menggunakan token, cache, atau status teknis untuk fitur-fiturnya. Konten yang disematkan, font, dan file eksternal dapat terhubung ke penyedia saat dimuat.

Kategori data, tujuan, dan cakupan berbagi dijelaskan di Kebijakan Privasi. Kebijakan penyedia tidak menggantikan tanggung jawab SoulLocket atas integrasinya.

5. Mengelola dan menarik pilihan

  • Buka Pengaturan → Pilihan privasi untuk beralih antara “Essential” dan “All”. Pilih “Penting” untuk membatalkan izin grup SDK opsional tanpa menghapus data aplikasi. Pilihan privasi iklan membuka pilihan UMP Google jika berlaku.
  • Kelola izin lokasi, kamera, mikrofon, notifikasi, kesehatan, dan iklan/pelacakan di pengaturan sistem operasi Anda. Kontrol yang tersedia bervariasi menurut perangkat.
  • Gunakan pengaturan privasi browser Anda untuk memeriksa/menghapus data situs web. Memblokir data penting dapat mengakhiri sesi masuk Anda atau mengganggu fitur.
  • Hubungi dukungan tentang hak privasi ketika antarmuka tidak memiliki tindakan yang diperlukan. Menghapus data aplikasi tidak boleh dianggap sebagai satu-satunya cara untuk membatalkan persetujuan.

6. Retensi dan efek pembersihan data

Data sesi mungkin kedaluwarsa pada akhir sesi; preferensi dan database lokal mungkin tetap ada sampai Anda menghapus data aplikasi/situs web. Cache memiliki masa pakainya sendiri dan dapat diunduh lagi. Keluar tidak menjamin penghapusan semua cache, unduhan, atau cadangan perangkat.

Ekspor atau sinkronkan data yang belum disimpan sebelum mengosongkan penyimpanan. Menghapus instalasi aplikasi, menghapus cookie, atau menonaktifkan izin tidak akan menghapus akun, data server, atau langganan Anda. Lihat Panduan Penghapusan Akun dan Data.
