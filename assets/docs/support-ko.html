1. 자주 묻는 질문

파트너와 어떻게 페어링하나요?

설정을 열고 → 파트너와 연결하세요. 한 사람이 12자리 초대장/QR을 만듭니다. 다른 하나는 그것을 입력하거나 스캔하고 작성자의 승인을 기다립니다. 주택 ID를 페어링 코드로 사용하지 마세요. 읽기 확인 전 데이터 경고.

휴대폰을 바꾸면 데이터를 복구할 수 있나요?

동기화된 데이터에 액세스하려면 올바른 계정으로 로그인하세요. 로컬에만 저장되었거나 아직 업로드되지 않은 콘텐츠는 전송이 보장되지 않습니다. 기기를 변경하기 전에 필요한 사항을 확인하고 내보내세요.

개인 반성이 전송되지 않거나 세션이 만료되었습니까?

문자 사본을 보관하고 연결을 확인하고 올바른 계정/하우스를 확인하세요. 다시 로그인하기 전에 초안을 저장하세요. 동기화하기 전에 문제 해결 단계로 앱 데이터를 지우지 마십시오.

내 계정을 어떻게 삭제하나요?

설정에서 계정 및 데이터 삭제를 사용하거나 앱 외부에서 요청 제출. 계정 삭제, 하우스 삭제, 구독 취소는 별도의 작업입니다.

2. 지원팀에 문의하세요

SoulLocket 운영 책임자: Trương Việt Hoàng.

지원 이메일 열기

이메일: support@soullocket.pro.vn. 앱 내 지원 영역을 이용할 수도 있습니다.

버튼을 누르면 이메일 앱이 열립니다. 자동으로 요청을 보내지 않습니다. 열리지 않으면 주소를 복사하여 사서함에서 메시지를 보내십시오.

  • 화면/작업, 시간, 플랫폼 및 버전을 설명합니다.
  • 귀하의 계정을 식별하는 데 필요한 경우 이메일/UID를 포함하십시오. 스크린샷의 비공개 콘텐츠를 수정합니다.
  • 거래의 경우 카드 세부정보가 아닌 주문 ID를 제공하세요.
지원에는 이메일, 소셜 미디어 또는 공개 양식을 통한 비밀번호, PIN 또는 일회성 코드가 필요하지 않습니다.

3. 데이터 권리 및 위반 신고

범위를 명시하여 지원할 개인 데이터에 대한 액세스, 수정, 내보내기 또는 삭제 요청을 보냅니다. 귀하의 권한을 확인해야 합니다. 다른 사람의 이메일을 안다고 해서 귀하가 그 사람의 데이터를 보거나 삭제할 수 있는 것은 아닙니다.

위반/괴롭힘의 경우 가능한 경우 앱에서 신고/차단을 사용하거나 지원팀에 문의하세요. 문제를 보고하기 위해 민감한 데이터를 재배포하지 마십시오.
