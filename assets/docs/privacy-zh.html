2. 数据及处理目的

账号与访问保护

电子邮箱、账号标识（UID）、个人资料姓名及照片、登录方式、身份验证会话、设备信息和通知令牌用于登录、账号恢复、通知和访问管理。Google 或 Facebook 等第三方登录仅在应用提供该方式且你选择使用时适用。

系统可能处理 IP 地址、浏览器及操作系统信息、应用设备标识、设备验证状态和防滥用信号。应用的设备保护信号设置不会清除服务器运行所必需的网络、身份验证或安全日志。

个人与共享空间（House 小屋）

姓名、头像、成员角色、配对日期、纪念日、在线状态和设置会被保存，用于显示、同步和访问控制。选择“情侣”界面模式本身并不代表两个账号已经配对。

你的内容与附件

日记、心情记录、照片、视频、消息、回应、社区帖子、便签、日历、书信、录音和工具内容会按照相应功能的需要进行处理，以便保存、显示、传送和同步。私密保险箱中的内容可能包含敏感信息；PIN 锁不等于端到端加密。

照片和文件可能保存在 Cloudflare R2、Firebase 基础设施或本地存储中，具体取决于处理流程和上传时间。应用通过访问链接、文件引用和缓存重新加载内容。

位置、健康与活动

如果你开启位置共享并授予相关权限，应用会处理坐标、位置历史和地点信息，用于地图、地点打卡或向同一小屋的另一位成员分享位置。授予后台位置权限后，即使应用不在前台，也可能继续更新位置。你可以在相应功能中停止共享，或在操作系统设置中撤销权限；这些操作不会自动删除已保存的历史记录。

健康、生理周期工具或睡眠跟踪可能处理你输入的信息、屏幕及活动信号，以及你允许从设备健康平台获取的睡眠数据。睡眠状态或历史可能同步到小屋。这些信息仅供参考，不属于医疗结论。

相机、麦克风与生物识别

相机和麦克风用于拍照、扫码、录音或应用提供的通信功能。生物识别验证由操作系统执行：SoulLocket 接收验证结果，而不会获得操作系统保存的指纹或人脸模板。

支付、广告与统计分析

商品信息、交易标识、验证令牌、VIP 权益和积分记录用于发放或恢复权益以及防范欺诈。敏感支付信息由相关支付平台处理；请勿向支持团队发送银行卡详情。

Google Mobile Ads/AdMob 可能处理广告标识、IP 地址、设备信息、广告展示和互动数据。Firebase Analytics 可能记录事件及页面导航；Crashlytics 处理错误、技术跟踪信息和附带标识以进行诊断。新的集成中，“仅必要”会关闭 Analytics/Crashlytics 数据收集，并阻止应用加载广告；“全部”不能替代 Google UMP 同意流程或操作系统权限。你可在“设置 → 隐私选项”中修改选择。旧版应用可能没有这些控制项。请参阅 Cookie 政策.

人工智能（AI）

使用 AI 时，你的请求、对话上下文及你选择附带的数据可能通过 SoulLocket 服务器或 Workers 传送至所配置的 AI 服务。代码集成了 Google Gemini，以及通过中间服务器转发的 OpenAI 兼容 API 路由；“兼容 OpenAI”并不意味着所有请求都由 OpenAI 直接处理。

请勿向 AI 发送密码、一次性验证码、银行卡详情或他人的私密数据。举报 AI 回复时，可能附带问题、回答和举报原因供支持团队审核。请勿认为所有 AI 内容都仅在你的设备上处理。

支持与删除请求

系统可能记录账号邮箱、你提供的姓名或小屋 ID、请求详情、IP 地址及浏览器信息，用于核实账号所有权、防止重复请求和提供支持。通过电子邮件或公开表单请求支持时，无需提供密码、PIN 或一次性验证码。

3. 谁可能接收或查看数据

  • 同一小屋中的另一位成员： 可按照各功能允许的范围查看共享数据。配对会授予访问共享空间的权限，而不只是添加一个头像。
  • 你所分享内容的查看者： 社区帖子、公开个人资料、回忆链接或卡片可能在该功能的分享范围内被查看。持有分享链接的人可能转发链接或保存副本；请勿公开邀请码或私人链接。
  • 基础设施提供商： Google/Firebase（身份验证、数据库、通知、存储、统计与诊断）、Cloudflare（R2、Workers 和内容分发），以及你使用的登录、广告和支付服务。
  • 地图与外部内容： Google Maps 或地图图块、OpenStreetMap/Nominatim 和 OSRM 可能接收查询或规划路线所需的 IP 地址、地点查询或坐标。外部文件、字体、播放器或嵌入页面在加载时可能直接连接其提供商。
  • AI 服务： 接收第2节所述的 AI 请求所需数据。实际提供商、处理地区和保存条件取决于服务配置；提交敏感信息前，你可以向隐私联系人咨询。
  • 获授权人员或有权机关： 在提供支持、处理违规、保护系统或响应适用法律下的有效请求所必需的范围内接收数据。

SoulLocket 不出售个人数据。服务提供商为运营服务而处理数据，并不意味着其可以超出已披露的目的自由使用数据。

配对前： 输入邀请码的人将转入创建邀请码者的小屋。原小屋的数据不会自动合并；原小屋若没有剩余成员，可能被清理。确认前请导出或保存需要保留的内容。请参阅 邀请与二维码指南.

4. 处理依据、选择与处理地点

处理数据是为了提供你请求的服务、执行你的分享选择、保护安全并履行适用的法律义务。需要同意或操作系统权限的处理活动，必须事先提供相关说明并让你作出选择；阅读本政策不能替代所有单独的同意。

Google、Cloudflare 及集成服务可能在越南境外处理或保存数据。请勿认为所有数据都存储在越南。你可以向我们询问与你的请求有关的数据接收方、处理地点和数据类型。

5. 保存、删除与残留数据

账号、个人资料和内容会在使用服务期间保留，直至通过相应功能或经处理的请求删除。不同类型的数据并不存在统一的自动删除期限。

  • 友好聊天的对话记忆窗口设计为约 3天。这并非所有 AI 举报、日志或 AI 提供商所持数据的保存期限；清理任务可能在数据到期后才执行。
  • 媒体文件可能先进入回收站或单独的清理队列。退出登录、卸载应用或撤销权限不会删除服务器数据。
  • 删除账号 与 分手／删除小屋数据 是不同的流程。相应的时间安排和范围见 账号与数据删除页面.
  • 共享内容、他人保存的副本、设备上的导出文件和缓存可能不会与账号同时消失。目前的自动删除流程并不保证清除所有 R2 媒体文件及每一条小屋相关记录；联系支持团队时，请说明仍需删除的个人数据。
  • 因法律义务、欺诈处理或争议而保留的数据，必须限于必要目的和期限。请联系支持团队了解适用于你的情况的数据类型、理由和期限；本政策不授权无限期保存数据。

6. 安全与限制

SoulLocket 使用身份验证、数据库访问控制、服务器访问检查、设备管理及各功能的专用锁。没有任何系统绝对安全；本文不承诺对所有日记、聊天或照片提供端到端加密。

请勿分享登录会话、PIN、一次性验证码或登录二维码。应用锁保护的是在设备上打开应用界面的操作；它本身不会改变同一小屋另一位成员的权限，也不会撤回已分享的副本。

7. 你的权利与请求

依据适用法律，你可以请求了解及访问数据、更正数据、获取副本或导出、删除数据、限制或反对处理、撤回同意及处理投诉。部分操作可在应用中完成；其他请求请发送给支持团队，或使用 账号删除表单.

请说明你的邮箱或 UID 及请求范围。提供或删除数据前，我们需要核实你是否有权提出请求；不需要提供密码或一次性验证码。撤回同意可能使相关功能无法继续使用，但不会使此前基于有效依据进行的处理失效。

你可以在操作系统中撤销相机、麦克风、位置、通知和健康权限。如果支持团队无法解决问题，你可以依据适用法律联系有权机关。

8. 儿童与人身安全

SoulLocket 并非专为低龄儿童设计的服务。用户必须满足适用的年龄、行为能力及父母或监护人同意要求。请勿根据描述禁止内容的“18+”标签推断服务的年龄限制。

父母或监护人若发现儿童数据被不当处理，可以联系隐私联系人，请求审查并采取措施。请勿使用应用秘密跟踪他人，或施压迫使他人分享位置。

9. 更新与相关文档

页面顶部的更新日期标识文档版本。处理目的或范围变更时，应通知用户，并在法律要求时重新取得同意；不能将沉默或继续使用视为同意所有新增目的。
