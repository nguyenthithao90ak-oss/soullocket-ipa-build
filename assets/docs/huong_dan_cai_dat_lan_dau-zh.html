1. 检查账号 2. 独自使用或配对 3. 保护设备与授予权限 4. 检查数据是否保存 5. 个性化设置

1. 检查账号

打开“设置”，检查邮箱、姓名、照片和当前小屋。换设备时请使用已有账号；不要为了恢复数据而创建新账号。

请阅读 隐私政策 与 Cookie 选项的限制。选择“仅必要”不会关闭所有 SDK。

2. 独自使用或配对

你可以独自使用应用。如需连接另一人，请打开 连接另一半：一人创建邀请或二维码，另一人输入或扫描并等待批准。情侣模式不会自动配对账号。

请先备份： 输入邀请码的人将转入创建者的小屋；原小屋的数据不会自动合并，没有成员的原小屋可能被清理。完成后请检查双方头像和连接日期。请参阅 配对指南.

3. 保护设备与授予权限

如果希望增加一道访问锁，可启用应用 PIN 和生物识别。仅为你使用的功能授予相机、麦克风、位置、健康或通知权限；你可以在操作系统设置中撤销权限。

开启后台位置或睡眠共享时，请检查小屋中谁能查看这些状态。PIN 本身不会限制另一位成员的权限。

4. 检查数据是否保存

  1. 打开“日记 → 心情”，输入一条简短内容并保存。
  2. 等待成功提示，然后返回列表检查。
  3. 尝试添加一张回忆照片，等待上传完成后重新打开。
  4. 出现错误时，请保留草稿并联系支持团队。尚不确定数据是否已同步时，不要卸载应用、清除存储或重新配对。

5. 个性化设置

通过可用的设置选项调整外观、纪念日、音乐或快捷入口。只使用你有权分享的内容或链接；外部内容可能连接到其他提供商。

请保留重要内容的副本。如需帮助，请打开 支持；如需停止使用服务并删除数据，请阅读 账号与小屋删除流程.
