1. Mga madalas itanong

Paano ko ipapares ang aking kapareha?

Buksan ang Mga Setting → Kumonekta sa iyong partner. Isang tao ang gumagawa ng 12-digit na imbitasyon/QR; ang isa ay pumapasok o nag-scan dito at naghihintay ng pag-apruba ng lumikha. Huwag gumamit ng House ID bilang code ng pagpapares. Basahin ang babala ng data bago kumpirmahin.

Maaari ko bang mabawi ang data kapag nagpapalit ng mga telepono?

Mag-sign in sa tamang account para ma-access ang naka-synchronize na data. Hindi garantisadong maililipat ang nilalamang lokal lamang o hindi pa na-upload. Suriin at i-export ang anumang kailangan mo bago magpalit ng mga device.

Hindi magpapadala ang mga personal na pagmumuni-muni, o nag-expire na ang session?

Magtago ng kopya ng iyong text, tingnan ang iyong koneksyon at kumpirmahin ang tamang account/Bahay. I-save ang mga draft bago mag-sign in muli; huwag i-clear ang data ng app bilang hakbang sa pag-troubleshoot bago mag-synchronize.

Paano ko tatanggalin ang aking account?

Gamitin ang Pagtanggal ng Account at Data sa Mga Setting o magsumite ng kahilingan sa labas ng app. Ang pagtanggal ng account, pagtanggal ng Bahay at pagkansela ng subscription ay magkahiwalay na pagkilos.

2. Makipag-ugnayan sa suporta

Taong responsable para sa mga pagpapatakbo ng SoulLocket: Trương Việt Hoàng.

Buksan ang email ng suporta

Email: hotroviethoangdev.lo.ve@gmail.com. Maaari mo ring gamitin ang in-app na lugar ng suporta.

Binubuksan ng button ang iyong email app; hindi ito awtomatikong nagpapadala ng kahilingan. Kung hindi ito bumukas, kopyahin ang address at magpadala ng mensahe mula sa iyong mailbox.

  • Ilarawan ang screen/aksyon, oras, platform at bersyon.
  • Isama ang iyong email/UID kung kinakailangan upang matukoy ang iyong account; i-redact ang pribadong nilalaman sa mga screenshot.
  • Para sa mga transaksyon, ibigay ang order ID, hindi ang mga detalye ng card.
Hindi kailangan ng suporta ang iyong password, PIN o isang beses na code sa pamamagitan ng email, social media o mga pampublikong form.

3. Mga karapatan sa data at mga ulat ng paglabag

Magpadala ng mga kahilingan sa pag-access, pagwawasto, pag-export o pagtanggal para masuportahan ng iyong personal na data, na nagsasaad ng saklaw. Kailangan naming i-verify ang iyong awtoridad; Ang pag-alam sa email ng ibang tao ay hindi nagbibigay sa iyo ng karapatan na tingnan o tanggalin ang kanilang data.

Para sa mga paglabag/panliligalig, gumamit ng pag-uulat/pag-block sa app kung saan available o makipag-ugnayan sa suporta. Huwag muling ipamahagi ang sensitibong data upang mag-ulat ng isyu.
