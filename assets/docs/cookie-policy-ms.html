1. Teknologi yang digunakan

Web mungkin menggunakan kuki, localStorage, sessionStorage dan IndexedDB. Aplikasi ini menggunakan SharedPreferences, storan pengesahan selamat, pangkalan data tempatan dan cache imej/fail. Ini bukan semua jenis kuki yang sama, tetapi semuanya mungkin menyimpan data pada peranti anda.

Halaman dasar ini tidak membenamkan kod pengiklanan atau Analitis. Borang pemadaman akaun menghantar data hanya apabila anda menyerahkannya; apl utama dan halaman kandungan lain mempunyai gelagat pemprosesan yang berasingan.

3. Maksud "Penting" dan "Semua".

Dalam penyepaduan baharu, "Essential" melumpuhkan pengumpulan Analitis/Crashlytics dan menyekat pemulaan dan pemuatan iklan melalui apl. "Semua" membenarkan SDK pilihan ini; iklan masih mesti dibenarkan oleh Google UMP dan mengikut kebenaran sistem pengendalian. Apl merekodkan pilihan, masa dan versi dokumen pada peranti; pilihan lama tanpa versi memerlukan pengesahan sekali lagi.

Penarikan balik menyekat permintaan baharu dan mengalih keluar iklan yang dimuatkan dalam apl; ia tidak dapat mengingat semula data yang telah dihantar atau sambungan yang sedang berjalan. SDK asli mungkin menyimpan laporan ranap sistem secara setempat; apl meminta pemadaman laporan yang tidak dihantar sebelum mendayakan pengumpulan. Versi apl lama mungkin tidak termasuk kawalan ini.

"Essential" tidak mematikan log masuk, penyegerakan, transaksi, keselamatan sistem atau setiap sambungan pihak ketiga. Ia tidak menggantikan kebenaran data sensitif, kebenaran sistem pengendalian atau persetujuan iklan yang berasingan.

4. Pembekal yang berkaitan

Firebase/Log Masuk Google, Facebook apabila digunakan untuk log masuk, Google Mobile Ads/AdMob, platform pembayaran, perkhidmatan peta dan infrastruktur Cloudflare boleh menggunakan token, cache atau keadaan teknikal untuk ciri mereka. Kandungan tertanam, fon dan fail luaran mungkin bersambung kepada pembekal apabila dimuatkan.

Kategori data, tujuan dan skop perkongsian diterangkan dalam Dasar Privasi. Dasar pembekal tidak menggantikan tanggungjawab SoulLocket untuk penyepaduannya.

5. Mengurus dan menarik balik pilihan

  • Buka Tetapan → Pilihan privasi untuk bertukar antara "Essential" dan "Semua". Pilih "Essential" untuk menarik balik kebenaran bagi kumpulan SDK pilihan tanpa mengosongkan data apl. Pilihan privasi iklan membuka pilihan UMP Google jika berkenaan.
  • Uruskan kebenaran lokasi, kamera, mikrofon, pemberitahuan, kesihatan dan pengiklanan/penjejakan dalam tetapan sistem pengendalian anda. Kawalan yang tersedia berbeza mengikut peranti.
  • Gunakan tetapan privasi penyemak imbas anda untuk memeriksa/memadam data tapak web. Menyekat data penting boleh menamatkan sesi log masuk anda atau mengganggu ciri.
  • Hubungi sokongan tentang hak privasi apabila antara muka tidak mempunyai tindakan yang diperlukan. Mengosongkan data apl tidak boleh dianggap sebagai satu-satunya cara untuk menarik balik kebenaran.

6. Pengekalan dan kesan mengosongkan data

Data sesi mungkin tamat tempoh pada penghujung sesi; keutamaan dan pangkalan data tempatan mungkin kekal sehingga anda mengosongkan data apl/tapak web. Cache mempunyai jangka hayatnya sendiri dan boleh dimuat turun semula. Log keluar tidak menjamin pengalihan keluar semua cache, muat turun atau sandaran peranti.

Eksport atau segerakkan data yang tidak disimpan sebelum mengosongkan storan. Menyahpasang apl, memadam kuki atau melumpuhkan kebenaran tidak memadamkan akaun, data pelayan atau langganan anda. Lihat Panduan Pemadaman Akaun dan Data.
