1. 使用されている技術

Web では、Cookie、localStorage、sessionStorage、および IndexedDB が使用される場合があります。このアプリは、SharedPreferences、安全な認証ストレージ、ローカル データベース、画像/ファイル キャッシュを使用します。これらはすべて同じ種類の Cookie ではありませんが、すべてデバイスにデータを保存する可能性があります。

これらのポリシー ページには、広告や分析コードが埋め込まれていません。アカウント削除フォームは、送信した場合にのみデータを送信します。メイン アプリと他のコンテンツ ページは別個の処理動作を持ちます。

2. 保存されるデータのカテゴリー

カテゴリ目的と例
認証と安全性サインイン セッション、トークン、デバイスのステータス、法的選択は、アクセスの維持と保護に役立ちます。
あなたの設定言語、外観、タブ、ロックまたは表示構成。これらの選択は、「必須」を選択した場合でも保存される場合があります。
データとキャッシュ下書き、同期キュー、ダウンロードされたイメージ/ファイル、ローカル データベースにはプライベート コンテンツが含まれる場合があります。自動的に匿名になるわけではありません。
診断・測定Firebase Analytics と Crashlytics は、それらの統合に従ってイベント、デバイス情報、エラー、技術識別子を処理する場合があります。
広告と取引広告の同意ステータス、広告識別子、インタラクション、購入または報酬の検証トークン。すべての広告活動を必須ストレージとして分類する必要はありません。

3. 「必須」と「すべて」の意味

新しい統合では、「Essential」は Analytics/Crashlytics の収集を無効にし、アプリによる広告の初期化と読み込みをブロックします。 「すべて」では、これらのオプションの SDK が許可されます。広告は引き続き Google UMP によって許可され、オペレーティング システムの権限に従う必要があります。アプリはデバイス上の選択、時間、ドキュメントのバージョンを記録します。バージョンのない従来の選択では、再度確認する必要があります。

取り消しにより、新しいリクエストがブロックされ、アプリに読み込まれた広告が削除されます。すでに送信されたデータや、すでに進行中の接続を呼び出すことはできません。ネイティブ SDK はクラッシュ レポートをローカルに保存する場合があります。アプリは、収集を有効にする前に、未送信レポートの削除を要求します。古いアプリのバージョンには、これらのコントロールが含まれていない可能性があります。

「Essential」では、サインイン、同期、トランザクション、システムの安全性、またはすべてのサードパーティ接続がオフになるわけではありません。これは、機密データのアクセス許可、オペレーティング システムのアクセス許可、または個別の広告の同意に代わるものではありません。

4. 関連プロバイダー

Firebase/Google サインイン、サインインに使用される Facebook、Google モバイル広告/AdMob、支払いプラットフォーム、マップ サービス、Cloudflare インフラストラクチャは、それらの機能にトークン、キャッシュ、または技術的状態を使用する場合があります。埋め込みコンテンツ、フォント、外部ファイルは、ロード時にプロバイダーに接続する場合があります。

データのカテゴリー、目的、共有範囲については、 プライバシーポリシー。プロバイダーのポリシーは、統合に対する SoulLocket の責任に代わるものではありません。

5. 選択肢の管理と撤回

  • 「設定」→「プライバシー」の選択を開いて、「必須」と「すべて」を切り替えます。アプリデータをクリアせずにオプションの SDK グループの権限を取り消すには、「必須」を選択します。広告プライバシーの選択により、該当する場合は Google UMP の選択肢が開きます。
  • オペレーティング システムの設定で、位置情報、カメラ、マイク、通知、状態、広告/追跡の権限を管理します。利用可能なコントロールはデバイスによって異なります。
  • ブラウザのプライバシー設定を使用して、Web サイトのデータを検査/削除します。重要なデータをブロックすると、サインイン セッションが終了したり、機能が中断されたりする可能性があります。
  • インターフェースに必要なアクションが欠けている場合は、プライバシー権についてサポートにお問い合わせください。アプリデータの消去を同意を撤回する唯一の方法として扱ってはなりません。

6. データの保持と消去の影響

セッション データはセッションの終了時に期限切れになる場合があります。アプリ/ウェブサイトのデータをクリアするまで、環境設定とローカル データベースが残る場合があります。キャッシュには独自の有効期間があり、再度ダウンロードされる可能性があります。サインアウトしても、すべてのキャッシュ、ダウンロード、またはデバイスのバックアップが削除されることは保証されません。

ストレージをクリアする前に、未保存のデータをエクスポートまたは同期してください。 アプリをアンインストールしたり、Cookie を削除したり、権限を無効にしても、アカウント、サーバー データ、サブスクリプションは削除されません。を参照してください。 アカウントとデータの削除ガイド.
