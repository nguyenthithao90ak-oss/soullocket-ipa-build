Erstmaliges SoulLocket-Setup

1. Überprüfen Sie Ihr Konto 2. Einzeln oder paarweise verwenden 3. Schützen Sie Ihr Gerät und erteilen Sie Berechtigungen 4. Überprüfen Sie, ob die Daten gespeichert werden 5. Personalisieren

1. Überprüfen Sie Ihr Konto

Öffnen Sie die Einstellungen und überprüfen Sie Ihre E-Mail-Adresse, Ihren Namen, Ihr Foto und Ihr aktuelles Haus. Nutzen Sie beim Gerätewechsel Ihr bestehendes Konto; Erstellen Sie kein neues Konto, um Daten wiederherzustellen.

Lesen Sie die Datenschutzrichtlinie und Einschränkungen bei der Cookie-Auswahl. Durch die Auswahl von „Essential“ wird nicht jedes SDK deaktiviert.

2. Einzeln oder paarweise verwenden

Sie können die App auch alleine nutzen. Um eine Verbindung herzustellen, öffnen Sie es Verbinde dich mit deinem Partner: Eine Person erstellt eine Einladung/QR, die andere Person gibt sie ein/scannt sie und wartet auf die Genehmigung. Im Kopplungsmodus werden Konten nicht automatisch gekoppelt.

Zuerst sichern: Die Person, die den Code eingibt, bewegt sich zum Haus des Erstellers. Die Daten des alten Hauses werden nicht automatisch zusammengeführt, und ein altes Haus ohne Mitglieder kann möglicherweise bereinigt werden. Überprüfen Sie anschließend beide Avatare und das Verbindungsdatum. Siehe die Pairing-Anleitung.

3. Schützen Sie Ihr Gerät und erteilen Sie Berechtigungen

Aktivieren Sie eine App-PIN und Biometrie, wenn Sie eine andere Zugriffssperre wünschen. Gewähren Sie Kamera-, Mikrofon-, Standort-, Gesundheits- oder Benachrichtigungsberechtigungen nur für die von Ihnen genutzten Funktionen. Sie können sie in den Betriebssystemeinstellungen widerrufen.

Wenn Sie die Standort-/Schlaffreigabe im Hintergrund aktivieren, prüfen Sie, wer im Haus den Status sehen kann. Eine PIN selbst schränkt die Berechtigungen des anderen Mitglieds nicht ein.

4. Überprüfen Sie, ob die Daten gespeichert werden

  1. Öffnen Sie Tagebuch → Reflexionen, geben Sie eine kurze Nachricht ein und speichern Sie.
  2. Warten Sie auf den Erfolg und kehren Sie zur Überprüfung zur Liste zurück.
  3. Versuchen Sie, ein Erinnerungsfoto hinzuzufügen, warten Sie, bis der Upload abgeschlossen ist, und öffnen Sie es erneut.
  4. Wenn ein Fehler auftritt, bewahren Sie Ihren Entwurf auf und wenden Sie sich an den Support. Deinstallieren Sie das Gerät nicht, löschen Sie nicht den Speicher und koppeln Sie es nicht erneut, wenn Sie nicht sicher sind, ob die Daten synchronisiert wurden.

5. Personalisieren

Passen Sie Aussehen, Jahrestage, Musik oder Verknüpfungen mithilfe der verfügbaren Abschnitte „Einstellungen“ an. Verwenden Sie nur Inhalte/Links, zu deren Weitergabe Sie berechtigt sind; Externe Inhalte können auf separate Anbieter verweisen.

Bewahren Sie Kopien wichtiger Inhalte auf. Für Hilfe öffnen Support; Um die Nutzung des Dienstes zu beenden und Daten zu löschen, lesen Sie die Konto-/Hauslöschvorgang.
