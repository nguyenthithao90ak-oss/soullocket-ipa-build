SoulLocket アカウントとデータを削除する

サインイン アカウントの削除と共有ハウス データの削除は別のアクションです。リクエストを送信しても、データがすでに削除されているわけではありません。

1. 正しいスコープを選択する

  • アカウントの削除: 現在のサインイン アカウントの閉鎖と関連データの処理を要求します。パートナーのハウス全体が自動的に削除されるわけではありません。
  • 解散・ハウスデータ削除： 共有スペースのクリーンアップを要求し、両方のユーザーのデータに影響を与える可能性があります。それ自体はサインイン アカウントを削除しません。
  • 個別のコンテンツの削除: コンテンツの一部だけを削除したい場合は、関連する日記、写真、投稿、またはユーティリティの削除アクションを使用します。
確認する前に、必要なものをすべてエクスポート/保存してください。アンインストールまたはサインアウトしても、削除リクエストは置き換えられません。アカウントを削除しても、支払いストアのサブスクリプションは自動的にキャンセルされません。

2. 現在のフローでの待機期間

正確な時刻がサーバーから返され、アプリに表示されます。以下のピリオドは、現在の処理コードを説明するものであり、すべてのコピーが正確な分に削除されることを保証するものではありません。

リクエストスケジュール設定
有効な識別ハウスなしでのアカウント削除ご依頼から3日後を予定しております。
ハウスによるアカウント削除現在の流れでは、下院に議員がまだ2人いない場合でも30日間の待機が設定されている。他の資格のあるメンバーが確認した場合、時間はその確認から 3 日にリセットされます。
シングルモードでの家の削除3日後の予定です。
別れ・カップル 家の削除他のメンバーの確認または 30 日間の待機期限を待ちます。スケジュール済みステータスに移行した後、削除までにさらに 1 日かかります。
アプリ外からのリクエスト即時削除ではなく、検証と処理のためにサポート リクエストを作成します。 7 日以内に自動的に完了するという保証はありません。サポートは、検証後に適切な進行状況/タイミングを伝える必要があります。

シェアハウスの場合、要求者は同じアカウントにサインインしている別のデバイスに切り替えて自己確認することはできません。インターフェイスがまだ許可している場合は、期限前かつ処理が開始される前にリクエストをキャンセル/取り消すことができます。完全に削除した後の回復は保証されません。

3. 扱うデータと現在の制限事項

現在のアカウント削除フローは、アカウント プロファイル、メンバーシップ リンク、プレゼンス/デバイス トークン、および一部の UID にリンクされたサポート リクエスト/レポートをクリーンアップしてから、認証アカウントを削除します。ハウス削除フローは、実装された範囲内でハウス、パブリック プロフィール、メッセージ ブランチ、通知、友達、GPS、招待状、およびハウスにリンクされたデータをクリーンアップします。

アカウントを削除すると、すべての古いコンテンツが同時に削除されるとは考えないでください。 シェアハウスのコンテンツ、Cloudflare R2 メディア、一部の Firestore データ、またはその他の記録には、追加のレビューと処理が必要になる場合があります。現在のメカニズムは、これらすべてのストアを完全にクリーンアップすることを約束するには十分ではありません。削除したい残りの個人データをサポート リクエストで指定してください。

他人が保持しているダウンロードしたコピー、スクリーンショット、デバイスのエクスポートはリモートで呼び出すことができません。法的義務、不正行為の処理、または紛争のために保持されるデータは制限されなければなりません。何が、なぜ、どのくらいの期間保持されるのかを尋ねることもできます。すべてのコミュニティ コンテンツが自動的に匿名になるという約束はありません。

4. アプリ内のアクション

  1. 正しいアカウントにサインインして開きます 設定 そして見つけてください アカウントとデータの削除 または データの分割/削除.
  2. 影響を受ける範囲と確認手順を読んでください。アカウントの削除には電子メール/ワンタイムコードの検証が含まれます。コードは公式アプリにのみ入力し、サポートへのメッセージには入力しないでください。
  3. 成功メッセージと予定時間を確認します。アカウント削除リクエストを作成した後、アプリによってサインアウトされる場合があります。
  4. 期限前に取り消すには、サインインし直し、保留中のリクエストのキャンセル アクションを探します。アクセスできない場合は、すぐにサポートに連絡してください。

前のリクエストのステータスを知らないで別のリクエストを作成しないでください。ネットワーク エラーは、サーバーが受信に失敗したことを証明するものではありません。

5. アプリ外から削除依頼をする

このフォームは、アプリを再インストールしたり、アプリにサインインしたりせずに使用できます。サポートは、それを受け取った後、行動する前に、あなたがアカウントを所有していることを確認する必要があります。電子メール/ハウス ID を知っていても、他人のデータを削除することは許可されません。

送信された情報、IP アドレス、ブラウザ情報は、次の手順に従って、受信、検証、および悪用防止のために処理されます。 プライバシーポリシー。パスワード、PIN、ワンタイム コード、または機密の身分証明書をメモに入力しないでください。

例: アカウントを削除し、残っている個人的な写真や日記のエントリを確認します。他人のアカウントの削除を要求しないでください。
