1. 开始使用

  1. 使用所选方式注册或登录。阅读条款、政策和隐私选项。
  2. 如有提示，请完成个人资料或小屋设置。在“设置”中检查姓名、头像及账号邮箱。
  3. 仅在需要相应功能时授予相机、麦克风、位置或通知权限。你可以在操作系统中修改权限。
  4. 阅读 首次设置指南 ，并保存一条简短记录以检查同步情况。

2. 配对与不同类型的二维码

配对两个账号

  1. 打开 设置 → 连接另一半.
  2. 希望保留自己小屋的人选择 创建我的邀请码，选择有效期，然后将12位数字邀请码或二维码发送给另一半。
  3. 另一人选择 输入另一半的邀请码，然后输入或粘贴邀请码，或扫描邀请二维码。
  4. 阅读数据提示，发送请求并等待创建者批准。知道小屋 ID 并不会自动获得访问权限。
  5. 完成后，检查双方头像、姓名和连接日期。“连接另一半”快捷入口也会显示双方头像和连接状态。
两个数据空间不会自动合并： 输入邀请码的人将转入创建者的小屋；原小屋若没有剩余成员，可能被清理。确认前请导出或保存需要保留的内容。不要公开邀请码或二维码图片。

三种不同类型的代码

  • 配对邀请码或二维码： 有有效期、仅能使用一次且需要批准的邀请。
  • 登录二维码： 在该流程可用时，需要登录的设备显示二维码，由已登录设备扫描并确认。不要扫描陌生人的登录二维码。
  • 个人资料或小屋二维码： 按照相应功能打开资料或进行分享；二维码本身不授予成员资格。

在设置中选择“情侣”不代表已经配对。如果已有另一半却仍显示创建邀请码，请检查账号、小屋和网络连接，然后联系支持团队；不要通过创建新小屋来排查问题。

3. 记录心情与保存回忆

  1. 打开 日记，然后选择 心情 进行记录，或选择 回忆 添加照片。
  2. 选择心情、填写内容并保存。等待成功提示，然后检查记录或照片是否出现在列表中。
  3. 如果登录会话已过期，请先保留尚未发送内容的副本，再重新登录正确的账号。
  4. 如果同步未完成，请检查网络、是否使用正确的小屋以及上传状态。仍有未同步草稿时，不要清除应用数据或卸载应用。

使用可用功能导出或下载内容，并检查保存的文件。导出文件不再受应用的隐私控制保护，请妥善存放。

4. 聊天与实用工具

通过当前应用版本提供的入口发送消息、分享内容、查看地图或打开工具和游戏。并非每个平台都提供所有功能。

  • 发送帖子、照片、卡片或链接前，请检查接收者和可见范围。
  • 开启并授予权限后，地图或位置共享可能在后台运行；不再希望分享时，请在相应功能或操作系统中关闭。
  • 录音需要麦克风权限；拍照或扫描二维码需要相机权限。仅发送文字消息不需要为此授予相机或麦克风权限。
  • 遭受骚扰时请举报、屏蔽或联系支持团队。AI 仅供参考，请勿向 AI 发送账号机密。

5. 安全与同步

如支持，请启用 PIN 或生物识别锁，检查已登录设备及隐私设置。PIN 锁定的是界面访问，本身不会改变同一小屋另一位成员的权限。

在新设备登录正确账号可能恢复已同步的数据。草稿、缓存、仅存于本地的内容或待上传内容可能不会迁移。换设备前，请核对数据并导出重要内容。

请勿分享密码、PIN、一次性验证码或登录二维码。提交错误截图时，请遮盖私人信息。

6. 交易与权益

如果当前应用版本提供付费功能，请在确认页面阅读价格、有效期和续订条款。恢复权益时请使用原购买商店账号。权益或奖励缺失时，请将交易编号或发生时间发送给支持团队核对；不要通过再次购买来排查问题。

卸载应用或删除账号不会自动取消订阅。请通过相关支付平台管理套餐。请参阅 交易条件.

7. 问题排查

  • 登录或会话过期： 检查网络、设备时间及账号对应的正确登录方式。退出登录前请保存草稿。
  • 邀请出错： 检查全部12位数字、有效期、是否已使用或正在等待批准，以及二维码类型。扫描失败时，可手动输入邀请码。
  • 心情或照片无法保存： 先保留副本，并检查已保存列表以避免重复；如果仍未出现，请报告问题。
  • 旧数据不见了： 检查账号和小屋；查明原因前，不要删除数据或重新配对。

请将平台、版本、页面、操作及错误发生时间发送至 支持。请勿发送密码、PIN 或一次性验证码。如需删除数据，请参阅 账号删除指南 ，而不是仅卸载应用。
