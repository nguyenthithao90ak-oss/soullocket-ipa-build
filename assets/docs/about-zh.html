1. 账号与共享空间

账号用于登录和管理访问权限。House（小屋）是存放个人资料、日记、回忆和共享内容的空间。你可以独自使用应用；如需与另一人连接，请打开 设置 → 连接另一半 ，创建、输入或扫描邀请。

配对成功后，页面会显示双方的头像、姓名和连接日期；页面外的快捷入口也会显示双方头像及已配对状态。选择情侣模式不等于完成两个账号的配对。

2. 功能分类

  • 首页：头像、天数计数、在线状态和快捷入口。
  • 日记与回忆：心情记录、保存的照片和同步内容。
  • 聊天与社区：各功能范围内的内容、互动和分享。
  • 当前应用版本提供的工具、游戏和创作内容。
  • 设置、安全、支持与隐私选项。

功能是否可用取决于平台、版本、设备权限和配置。源代码中存在某个功能文件，并不代表该功能在每个发行版本中都已启用或正常可用。

3. 数据与基础设施

SoulLocket 使用 Firebase 提供身份验证、数据库和通知服务，并使用 Cloudflare R2/Workers 处理相关文件及服务流程。除服务器上的数据外，设备上也可能保存草稿、缓存和下载内容。

同一小屋中的另一位成员可以按照各功能的权限访问共享内容；设置 PIN 锁本身并不会让共享内容仅对你可见。配对前，请阅读关于原有小屋数据的提示，并备份需要保留的内容。

请参阅 隐私政策 ，了解服务提供商、数据处理及你的权利。

4. 需要了解的限制

SoulLocket 不保证绝对安全、持续无中断运行或恢复所有数据。它不能替代紧急服务或专业建议。AI 内容、地图和在线状态可能不准确或存在延迟。

不得使用 SoulLocket 秘密跟踪他人、胁迫他人，或分享你无权使用的数据。
