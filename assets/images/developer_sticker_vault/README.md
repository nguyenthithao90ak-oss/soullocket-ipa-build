# Developer sticker vault

Kho dự phòng gồm **50 sticker phát triển ứng dụng**, chia thành 5 atlas (mỗi atlas 5 cột × 2 hàng).

Trạng thái hiện tại: **chưa tích hợp vào app**.

- Không khai báo thư mục này trong `pubspec.yaml`.
- Không tham chiếu các atlas từ mã Dart.
- Chỉ dùng `manifest.json` để tra cứu ID và tọa độ.
- Chỉ tích hợp khi chủ dự án yêu cầu trong một lượt sau.

Các nhóm gồm công cụ/hạ tầng, quy trình sản phẩm, cảm xúc lập trình viên, tính năng di động và phản ứng phát triển.
