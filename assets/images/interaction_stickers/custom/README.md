Sticker hoàn chỉnh sẵn sàng nối vào app.

Nếu bạn muốn mình thêm sticker mới vào luồng sticker hiện tại, hãy đặt file vào đây rồi nhắn:

`thêm toàn bộ sticker trong assets/images/interaction_stickers/custom/ vào app`

Ưu tiên:
- `png` hoặc `webp`
- nền trong suốt nếu có
- tên file ngắn, không dấu, ví dụ `hello_01.png`
